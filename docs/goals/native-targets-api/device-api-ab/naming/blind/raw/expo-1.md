1. `native`: As an Expo/React Native dev, "native" is the word I already use for "the platform's real component, not one I drew in JS", so `native.sheet` and `native.tabbar` read correctly right away.
2. `system`: It says "the OS supplies this", the same way we talk about the system sheet, system menu and system camera, and it still makes sense on the web, where the browser plays the system's part.
3. `os`: It's short and says plainly that the operating system or browser owns the look and the motion, and `os.sheet` and `os.menu` sit cleanly next to the headless families.
