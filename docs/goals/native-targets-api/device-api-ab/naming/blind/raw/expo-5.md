1. `native`: React Native and Expo devs already say "native" for the platform's real component as opposed to a JS-drawn one, so `native.sheet` reads as "the real iOS/Android sheet".
2. `system`: Apple and Google call these the system sheet, system tab bar and system menu, and "system" also fits the web build, where it means the browser's own version.
3. `host`: it says "whatever the host platform gives you" without implying iOS or Android only, so it still makes sense for the browser equivalents on the web.
