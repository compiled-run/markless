1. `native`: In React Native and Expo, "native" is the word we already use for the platform's real UI, like native tabs, native sheets and native modules, so `native.sheet` means the iOS or Android sheet rather than one I build myself.
2. `system`: It says the OS draws it, the way people say "the system sheet" or "the system menu", and it still makes sense on the web, where the browser supplies the version.
3. `os`: It's short and says plainly "the operating system's version", so `os.tabbar` and `os.camera` read as the real platform pieces.
