1. `native`: Native is the word iOS and Android developers use for the platform's own controls, like a native sheet, native tab bar or native menu, as opposed to custom-drawn ones.
2. `system`: Apple and Google both say "system" for components the OS provides (system sheet, system menu, system camera UI), so `system.sheet` reads as "the OS draws it."
3. `os`: It is short and says the operating system supplies the view, and on the web build it still makes sense as "the browser's own."
