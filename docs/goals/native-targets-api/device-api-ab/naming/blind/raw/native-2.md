1. `native`: iOS and Android developers already say "native" when they mean the platform's real sheet, tab bar or menu, as opposed to one drawn by hand.
2. `system`: Apple and Google both call these "system" components (system sheet, system menu, system tab bar), so it signals that the platform supplies them.
3. `os`: It's short and clearly means "whatever this operating system provides", and it doesn't clash with `platform` or `device`.
