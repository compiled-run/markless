1. `native`: This is the word iOS and Android developers already use for the platform's real UIKit/SwiftUI or Compose control as opposed to a custom-drawn one, so `native.sheet` reads straight away as "the real system sheet".
2. `system`: Apple and Google both call these "system" components (system sheet, system tab bar, system menu), and it clearly sets them apart from your own drawn headless families.
3. `os`: It's short and says "the operating system's own version" (on the web, the browser's), though it reads a little terser and is less common in UI code than `native`.
