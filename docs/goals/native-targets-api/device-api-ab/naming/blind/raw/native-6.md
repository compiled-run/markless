1. `native`: Mobile developers already say "native" for the real platform component, like a native sheet, native tab bar or native camera, as opposed to one you draw yourself.
2. `system`: Apple and Android both call these "system" UI (system sheet, system menu, system camera), so `system.sheet` reads as "the OS's own sheet."
3. `os`: It's short and says plainly that the operating system renders this, not your code, though it can be confused with an OS-version check.
