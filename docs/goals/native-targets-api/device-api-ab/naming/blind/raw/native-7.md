1. `native`: iOS and Android developers already say "native" for the platform's real UIKit/SwiftUI or Android View/Compose component, as opposed to a custom drawn one, so `native.sheet` reads as "the real system sheet."
2. `system`: Apple and Google docs call these the system sheet, system tab bar and system menu, and the name says the OS supplies the look and the motion.
3. `os`: It's short and means "whatever the operating system provides," so in the web build it reads naturally as the browser's own version.
