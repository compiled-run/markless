1. `native`: iOS and Android developers already say "native" for the system's real UI as opposed to something custom-drawn, so `native.sheet` reads as the system sheet.
2. `system`: Apple and Google docs talk about "system" components and the "system sheet", so the name signals that the OS owns the frame, drag and motion.
3. `os`: It's short and clearly means the operating system's version of the component, but on the website build "OS" is a looser fit for the browser.
