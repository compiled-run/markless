1. `native`: as a web developer I'd call the platform's built-in version the "native" one, as in native app or native UI, so `native.sheet` reads as "the real iOS/Android sheet, not one I drew myself."
2. `system`: it means the operating system's own component, the same way I'd talk about a system dialog or system font.
3. `os`: it's short and says the OS supplies this piece, though "OS" doesn't quite cover the browser fallback on the web.
