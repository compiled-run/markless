1. `native`: says plainly that you get the platform's real built-in control (the real iOS sheet, Android tab bar, or the browser's own element) instead of one you draw yourself.
2. `system`: reads as "use the system's built-in version," the way web developers already say system fonts or system UI.
3. `builtin`: says clearly that the component comes with the platform rather than from your own markup or a headless family.
