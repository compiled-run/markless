1. `native`: Web developers already say "native" for the browser's or phone's built-in thing, such as a native select or a native app, so `<native.sheet>` reads as "the real platform one, not one I drew."
2. `system`: It suggests the operating system's own UI, like system menus and system dialogs, which is exactly what these are.
3. `os`: It's short and makes clear the component comes from the operating system rather than from my own markup, though it fits the website build less neatly.
