1. `native`: it's the word web developers already use for "the platform's real thing, not something we drew ourselves," as in native select versus custom dropdown, or React Native.
2. `system`: it reads as "the OS's built-in version," like system fonts or the system share dialog, and doesn't suggest a headless or custom component.
3. `os`: it's short and makes clear the operating system or browser supplies the control, not your own markup.
