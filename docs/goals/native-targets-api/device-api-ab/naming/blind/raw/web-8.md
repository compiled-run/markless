1. `native`: Web developers already say "native" to mean "the real built-in one, not a JavaScript copy", as in native `<dialog>` or native select, so `native.sheet` reads straight away as "the phone's real sheet, or the browser's own version on the web".
2. `system`: It says the operating system or browser draws the frame and handles the motion, the way "system font" or "system dialog" means "whatever the OS provides".
3. `os`: It is short and clearly means "the operating system's own UI", although it fits the website build less well because there the browser supplies it, not the OS.
