1: I'd guess it's a set of components that wrap the phone's built-in features and screens: bottom sheets, camera, PDF viewer, tab bar and menus. On iPhone and Android they'd show the real system versions, and on the website they'd fall back to some web equivalent.

2: I'd expect other hardware and OS features, like geolocation, notifications, share sheet, haptics/vibration, file picker, clipboard, biometrics, alerts/action sheets, date pickers and maybe a status bar or safe-area helper.

3: I'd be surprised to find ordinary styled UI pieces such as buttons, cards or form layouts, or anything to do with routing, data fetching or state management. Cross-platform visual widgets with no system equivalent would also feel out of place.

4: Mostly the operating system: on iOS and Android I'd expect it to look like the platform's own sheet, and I'd have little styling control beyond what I put inside it. On the web, I'd guess Markless supplies a default look that I can probably restyle with CSS.
