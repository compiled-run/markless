A3. `primitives`: Radix calls its unstyled building blocks "primitives", so the name tells you these are low-level parts you put together and style yourself.

B1. `ui`: `<ui.button>` reads naturally and matches the package name, so I wouldn't have to remember a second word.

B2. `base`: `<base.button>` suggests a plain building block with no styling, which fits single pieces that don't belong to a family.

B3. `el`: `<el.label>` is short for "element", which fits pieces that are basically one element each, and it's quick to type.
