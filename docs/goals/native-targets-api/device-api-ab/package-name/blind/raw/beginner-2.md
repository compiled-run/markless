A1. `ui`: short and obvious, it's the UI component library, and it matches the `ui-*` naming I'd expect to see on the parts.
A2. `headless`: people in React already say "headless components" for behaviour and accessibility with no styles, like Headless UI and Radix.
A3. `primitives`: Radix calls these primitives, so I'd guess right away that they're unstyled building blocks.
B1. `ui`: `<ui.button>` reads naturally, and it means "a basic UI piece" without me having to learn a new word.
B2. `base`: `<base.button>` sounds like the plain base version of a button that I style myself.
B3. `core`: `<core.button>` suggests the core standalone pieces that aren't part of a family, though it's close to the `@markless/core` package name.
