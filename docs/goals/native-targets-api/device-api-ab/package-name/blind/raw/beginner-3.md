A1. `ui`: It's short and obvious, like "these are the UI components," and I'd guess it without having to look it up.
A2. `headless`: People already say "headless UI" for components that come with behaviour and accessibility but no styles, so it tells me right away I'm doing the CSS myself.
A3. `primitives`: Radix calls its unstyled building blocks primitives, so it sounds like the low-level parts I build my own components from.
B1. `ui`: `<ui.button>` reads naturally and matches the package name, so there's only one word to remember.
B2. `base`: `<base.button>` sounds like the basic standalone pieces that every family builds on.
B3. `core`: It says "the essential single pieces," though since `@markless/core` already exists it could get confusing.
