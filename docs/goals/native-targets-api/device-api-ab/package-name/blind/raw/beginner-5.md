A1. `ui`: Short and obvious. It's the UI components package, and `@markless/ui` reads like shadcn or Radix to me.
A2. `headless`: It says right away that there's no styling and I bring my own CSS, like Headless UI.
A3. `components`: Very plain. Anyone would guess it holds the components, though it's long to type.
B1. `ui`: `<ui.button>` reads naturally as "the UI button" and matches the package name.
B2. `base`: These are the basic building blocks that aren't families, so `<base.button>` feels right.
B3. `el`: Short for "element". `<el.label>` is quick to type and suggests a single simple piece.
