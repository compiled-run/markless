A1. `ui`: it's the first name I'd guess for a components library, and it's short to type in every import.
A2. `headless`: from tutorials I know "headless" means you get the behaviour and accessibility but no styles, which is exactly what this is.
A3. `components`: plain and obvious, so nobody has to guess what's inside.
B1. `ui`: `<ui.button>` reads naturally, like "the UI button", and it would match the package name.
B2. `base`: these are the basic single pieces that the bigger families are built from.
B3. `el`: short for "element", since a button, label or separator is basically one element with behaviour added.
