A1. `ui`: It's short and obvious. Any web developer sees `@markless/ui` and knows it's the component library, and it doesn't suggest a visual style.
A2. `headless`: This is the term people already use for "behaviour and accessibility, no styles" (Headless UI, Radix-style), so it tells you right away that you bring your own CSS.
A3. `primitives`: It says these are the low-level building blocks you put together and style yourself, the way Radix Primitives uses the word.
B1. `ui`: `<ui.button>` and `<ui.label>` read naturally and match what people expect from a generic UI piece, especially if the package is `@markless/ui`.
B2. `base`: It says these are the basic single elements that families and apps build on, and it's short enough to type everywhere.
B3. `core`: It reads as "the essential single pieces", but it could be confused with the `@markless/core` package, so it comes third.
