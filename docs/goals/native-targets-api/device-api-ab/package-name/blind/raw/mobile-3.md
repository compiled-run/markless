A1. `ui`: It's the word I already use every day (UIKit, SwiftUI, Compose UI), so `@markless/ui` reads straight away as "the components package."
A2. `kit`: Like UIKit, it says "a set of building blocks you assemble yourself," which fits a package with no styling.
A3. `components`: It's plain and hard to misread, the way people talk about React Native component libraries, though it's long to type.
B1. `ui`: `<ui.button>` and `<ui.label>` read naturally and match the package name, so there's nothing extra to learn.
B2. `control`: Button, label and separator are what I'd call controls (UIControl, Android widgets), and it keeps them apart from the families.
B3. `base`: It tells you these are the small single pieces that everything else is built from.
Tools used: none
