1. `ui`: That's what most libraries call their component package (like shadcn/ui or Chakra UI), and a tab bar and a modal are UI components.
2. `components`: If they didn't call it `ui`, this is the next most obvious name for a package of tab bars, dialogs and other pieces.
3. `headless`: I'll be styling them myself, and I've seen "headless" used for unstyled components (Headless UI), so it could be named for that.
