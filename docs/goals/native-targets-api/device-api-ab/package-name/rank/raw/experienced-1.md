1. `ui`: it's the first name I'd try for unstyled components like a tab bar and a dialog, since most component libraries I've used ship under "ui".
2. `components`: it's the plain, literal name for a set of reusable components when there's no "ui" package.
3. `headless`: libraries that give you behaviour and accessibility with no styles, so you style them yourself, often go by this name.
