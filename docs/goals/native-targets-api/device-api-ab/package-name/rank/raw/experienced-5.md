1. `ui`: Unstyled tab bars and dialogs are what component libraries usually ship, and `@markless/ui` is the name I'd expect a framework's own UI kit to have.
2. `components`: If they didn't go with `ui`, this is the next most common name for a package of building blocks like tabs and modals.
3. `headless`: These are components I style myself, and "headless" is the word libraries like Headless UI use for working but unstyled components.
