1. `ui`: Tab bars and modal dialogs are UI components, and unstyled components that work on every platform usually ship as a "ui" package.
2. `components`: This is the plain name I'd expect for a package of reusable building blocks like tabs and dialogs.
3. `headless`: I want components with no styling so I can style them myself, and "headless" is the usual term for that.
