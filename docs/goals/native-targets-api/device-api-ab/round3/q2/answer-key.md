# Q2 questions and what is recorded

Written before any reader ran. Q2 has no right answer for the meaning question: it records which meaning readers find
unsurprising.

## Spellings and labels

| Label | Spelling |
| --- | --- |
| JE | `platform.ios`, `platform.macos`, `platform.web` (lowercase booleans) |
| UF | `platform.iOS`, `platform.macOS`, `platform.web` (brand casing) |
| XB | `platform.os === 'ios'` |
| DL | `platform === 'ios'` (added: all 8 blind writers guessed this form; it is not in the brief) |

## Blind writers (8)

They saw only that `@markless/device` exports `platform` and the five builds. Recorded: the spelling they wrote, the
alternatives they named, their preference, and their answer to "in the website build opened in Safari on a Mac, what does
your macOS test give?"

## Readers (12, three per spelling, one spelling each in message 1)

Recorded for message 1: who sees each piece; question 2's letter (a: the browser is on a Mac; b: it is the website
build, not the Mac app; c: cannot tell); question 3 (does Safari on an iPhone see the Wallet button); confidence.
Recorded for message 2: ranking of the four spellings, preferred spelling, and whether a spelling made the meaning clearer.
