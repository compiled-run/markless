## Ranking
1. JE: reads like plain English (`platform.web`, `platform.ios`), with no comparison clutter and consistent lowercase.
2. DL: almost as short, and comparing one value against `'web'`, `'macos'` and the rest makes it clear that only one can be true.
3. XB: means the same as DL, but the `.os ===` adds noise. The name `os` also slightly suggests the real operating system, which is misleading when one of its values is `'web'`.
4. UF: just as short as JE, but the mixed casing (`macOS`, `iOS` next to `web`, `android`) means I'd have to remember the exact spelling of each name, which invites typos.

B: DL, or XB as a close second. A single value compared against a fixed list of options can be checked by TypeScript (a misspelled `'macOS'` would be caught), works in a `switch`, and makes it obvious that the five builds exclude each other. JE is nicer to read, but with separate true/false flags I'd always wonder whether two can be true at once.

C: DL and XB are clearer. Because `'web'` is one of the same values as `'macos'`, the website build cannot also be `'macos'`, so the Mac test means "this is the Mac app". In JE and UF, `platform.web` and `platform.macos` are separate flags, and nothing stops both from being true for Safari on a Mac. There, (a) becomes a real possibility, and I'd pick (c) for those two spellings. None of the spellings changes my answer for the version I was given (XB): it stays (b).
