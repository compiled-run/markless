## Ranking
1. `system`: the device or browser draws what is inside; you only place the box. (my addition)
2. `native`: drawn by the platform's own UI rather than by Markless, which fits iPhone and Android well.
3. `view`: a display box, though nearly every part could be called a view, so it says little.
4. `element`: a plain element, which tells you nothing about what this one is.

B: `native` suggests these are native-only (iPhone and Android), or a bridge to native code. On the website they are browser features, not native views, and readers may also confuse it with "native HTML elements". `element` clashes with `element()` from `@markless/core`, so it suggests a handle or binding helper rather than a drawn box. `view` suggests a layout container (like React Native's `View`) that could hold children, but these boxes cannot.

Tools used: none
