1. `native`: says the device draws what is inside the box, the system camera preview and PDF view on iPhone and Android, so the author cannot style it.
2. `view`: suggests a display box that shows something. That fits, but it is vague because every component is a view of some kind.
3. `element`: suggests a generic element or element handle. It says nothing about these two being special.

A name I would rank above `native`:
0. `system`: says the operating system or browser draws the contents. It also fits the website, where the content is the browser's camera picture and PDF viewer, not native code.

B: Yes, two of them do. `native` suggests the elements exist only in the iPhone and Android apps, or that they wrap native code.
