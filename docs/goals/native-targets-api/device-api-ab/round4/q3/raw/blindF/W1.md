## Invented API
```ts
// Module: @markless/device
// One element shows any device object; the box is sized and placed with `class`.
export declare function View(props: { el: Camera | Pdf; class?: string }): Element;
```

```tsx
// file: pages/media.tsrx
import { state } from '@markless/core';
import { camera, pdf, View, type Photo } from '@markless/device';
import { tabs, base } from '@markless/ui';

function CameraPanel() @{
	const cam = camera({ facing: 'back' });
	let last = state<Photo | null>(null);

	<div class="panel">
		<View el={cam} class="fill" />
		<div class="controls">
			<button disabled={!cam.ready} onClick={async () => (last = await cam.takePhoto())}>Shutter</button>
			<base.button pressed={cam.facing === 'front'} onChange={() => cam.flip()}>
				Flip camera
			</base.button>
		</div>
		@if (last) {
			<img class="fill" src={last.url} alt="Last photo" />
		}
	</div>
}

function DocumentPanel() @{
	const doc = pdf('/guide.pdf');

	<div class="panel">
		<View el={doc} class="fill" />
		<div class="controls">
			<button disabled={doc.page <= 1} onClick={() => (doc.page = doc.page - 1)}>Previous</button>
			<span>Page {doc.page} of {doc.pages}</span>
			<button disabled={doc.pages === 0 || doc.page >= doc.pages} onClick={() => (doc.page = doc.page + 1)}>Next</button>
		</div>
	</div>
}

export default function Media() @{
	let tab = state('camera');

	<main>
		<style>{`
			.panel { display: flex; flex-direction: column; gap: 0.5rem; }
			.fill { display: block; width: 100%; }
			.controls { display: flex; gap: 0.5rem; align-items: center; }
		`}</style>
		<tabs.root value={tab} onChange={(value) => (tab = value)}>
			<tabs.list>
				<tabs.trigger value="camera">Camera</tabs.trigger>
				<tabs.trigger value="document">Document</tabs.trigger>
			</tabs.list>
			<tabs.content value="camera">
				<CameraPanel />
			</tabs.content>
			<tabs.content value="document">
				<DocumentPanel />
			</tabs.content>
		</tabs.root>
	</main>
}
```

## Guesses
- I guessed the element's name and where it comes from: a component called `View`, exported from `@markless/device`. The sheet does not publish either.
- `base.button` has no `onClick`. So the flip button is a toggle button: it is pressed when the front camera is on, and its `onChange` calls `cam.flip()`.
- The shutter is a plain `<button>`. `takePhoto()` waits until the camera is ready, so the `disabled` check is only a courtesy.
- I assumed `tabs.root` with `value` and `onChange` works as a controlled tab set, starting on `'camera'`.
- I assumed that assigning `doc.page` and reading the live fields `cam.facing`, `cam.ready` and `doc.pages` update the page reactively.
- I assumed a `<style>` element with a template string is allowed inside the root element.
- I assumed the camera keeps running while its panel is hidden, because the content part stays in the page.

## Website
- Camera preview: the browser's live camera picture after the visitor allows camera access, sized to the panel width.
- PDF page: the browser's built-in PDF viewer showing `/guide.pdf` at the current page, filling the panel width.

## Answers
A: From `@markless/device`. That package defines the camera and PDF objects the element shows, and on each platform it draws the system's own camera preview and PDF view. Putting the element in `@markless/ui` would not fit, because that package holds families of parts with behaviour and this box has neither.
B: `<View el={cam} />`. Two other spellings I would find natural: `<Device el={cam} />` and `<device.view el={cam} />`.
