## Invented API

```ts
// Module: @markless/device
// The one element that shows any device object (Camera, Pdf, ...). The device draws what is inside the box.
export declare function View(props: { el: Camera | Pdf; class?: string }): Element;
```

```tsx
// file: pages/media.tsrx
import { state } from '@markless/core';
import { base, tabs } from '@markless/ui';
import { camera, pdf, View, type Photo } from '@markless/device';

function CameraPanel() @{
	const cam = camera({ facing: 'back' });
	let photo = state<Photo | null>(null);

	<section class="panel">
		<View el={cam} class="fill" />
		<div class="controls">
			<button
				disabled={!cam.ready}
				onClick={async () => {
					photo = await cam.takePhoto();
				}}
			>
				Take photo
			</button>
			<base.button pressed={cam.facing === 'front'} onChange={() => cam.flip()}>
				Flip camera
			</base.button>
		</div>
		@if (photo) {
			<img class="fill" src={photo.url} alt="Last photo taken" />
		}
	</section>
}

function DocumentPanel() @{
	const doc = pdf('/guide.pdf');

	<section class="panel">
		<View el={doc} class="fill" />
		<div class="controls">
			<button disabled={doc.page <= 1} onClick={() => doc.page--}>Previous</button>
			<span>Page {doc.page} of {doc.pages}</span>
			<button disabled={doc.pages === 0 || doc.page >= doc.pages} onClick={() => doc.page++}>Next</button>
		</div>
	</section>
}

export default function Media() @{
	let tab = state('camera');

	<main>
		<style>{`
			.panel { display: flex; flex-direction: column; gap: 0.5rem; }
			.fill { display: block; width: 100%; }
			[ui-selected] { font-weight: bold; }
		`}</style>
		<tabs.root value={tab} onChange={(value) => (tab = value)}>
			<tabs.list>
				<tabs.trigger value="camera">Camera</tabs.trigger>
				<tabs.trigger value="document">Document</tabs.trigger>
			</tabs.list>
			<tabs.content value="camera">
				<CameraPanel />
			</tabs.content>
			<tabs.content value="document">
				<DocumentPanel />
			</tabs.content>
		</tabs.root>
	</main>
}
```

Confidence: 2/5

## Guesses

- The element's name (`View`) and the module it comes from (`@markless/device`). The sheet does not publish either.
- I capitalized the tag so the JSX compiler treats it as a component. A lowercase `<view>` might be taken for a plain HTML element.
- `base.button` has no `onClick` in its props. So the flip button is a toggle: `pressed` follows `cam.facing`, and `onChange` calls `cam.flip()`. The shutter is a native `<button>`.
- Fields on device objects (`cam.ready`, `cam.facing`, `doc.page`, `doc.pages`) can be read live in markup. `doc.page--` / `doc.page++` assign through and move the PDF to that page.
- An async `onClick` handler is allowed, and assigning `photo` after the `await` updates the page. `@if (photo)` narrows away `null`, so `photo.url` type-checks.
- Panels the tabs are not showing stay mounted, so the camera keeps running while the Document tab is open.
- `tabs.root` can be driven from state through `value` and `onChange`.
- A `<style>` block with a template string inside the root element is valid `.tsrx`.
- Text and `{}` expressions can be mixed in one `<span>` (`Page {doc.page} of {doc.pages}`).

## Website

Camera preview: after the visitor allows camera access, they see the live picture from the browser's camera, filling the panel width.
PDF page: the browser's built-in PDF viewer shows `/guide.pdf` at the current page, filling the panel width.

## Answers

A: From `@markless/device`. That package defines the objects the element shows (`camera()`, `pdf()`) and their types. The element exists only to show those objects and has no parts or behaviour, so it is not a `@markless/ui` family.
B: `<View el={cam} />`. Two other spellings I would find natural: `<device.view el={cam} />` and `<DeviceView el={cam} />`.

Tools used: none
