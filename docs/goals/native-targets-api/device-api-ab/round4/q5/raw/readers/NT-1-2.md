## Ranking
1. NT (`native`): it is the usual word for "the platform's own control", as in native apps and native controls, so "drawn by the platform, not the page" comes through on its own. The downside is that it leans toward phone UI.
2. SY (`system`): "system sheet" and "system camera" clearly say "the OS draws this", which fits "not drawn by the page" well. It is also widely used for design systems, and on the website it is less clear whether the browser counts as the "system".
3. OS (`os`): it ties the meaning to the operating system, so it reads as iPhone or Android only. On the website it suggests the element is missing, or that the computer's OS draws it rather than the browser. It is also short enough to look like an abbreviation for something else.

B: NT can't tell, leaning yes, because the browser has native elements too (`<dialog>`, its PDF viewer). SY can't tell, because the browser could count as the system, but it's unclear. OS leans no, because it suggests the phone's operating system, and a website runs in a browser rather than directly on the OS.

C: SY yes, because "system" next to `base` and `drawer` in a UI package reads naturally as "design system". NT somewhat, because it could be a theme or library called "Native", though the word usually means platform-drawn. OS no, or barely, because it is hard to read as a component library name.

D: Both, but mostly the phone's own UI. My first reading is iPhone and Android controls. That it also means the browser's built-in element on the website is something I inferred, mainly from the page using these elements with no platform check. The word alone doesn't tell you.
