## Ranking
1. SY (`system`): "the system draws it" fits both the phone's operating system and the browser, which is the platform on the website. It also contrasts cleanly with author-built parts like `base` and `drawer`.
2. NT (`native`): commonly means "provided by the platform, not the page", but in mobile slang it pulls toward "phone app as opposed to the web", so the website case gets murky.
3. OS (`os`): strongly suggests the operating system, meaning iOS or Android. A browser isn't usually called an OS, so on the website it reads as "probably absent" or "faked". It's also terse and could look like a utility module.

B: SY: yes, because "system" can mean the browser on the website. NT: can't tell, because "native" often means "not the web", though a browser has native elements too. OS: no, it leans toward apps only.

C: SY: somewhat, because "system" is often used in "design system", and `system.button` could pass for a design-system namespace. NT: somewhat, since it sits beside `base` and `drawer` like a component family, but the word itself points to the platform. OS: no, it reads as the platform and doesn't sound like a component library.

D: Both, but it leans toward the phone's own UI. My first instinct was "iPhone or Android control". I read it as "the browser's built-in element" on the website only because nothing in the code puts it behind a platform check.
