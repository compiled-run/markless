## Ranking
1. SY: "system" most directly says "the system draws this, not the page". It also reads naturally on the website, where the system is the browser, and it echoes the "system sheet" wording people already use for phone UI.
2. NT: "native" clearly means the phone's own UI in the apps. On the website it is ambiguous: it could mean the browser's built-in element, or that there is nothing to show because the page isn't running on a phone.
3. OS: "os" names the operating system, and a website is not running on an operating system's UI. It points toward phone-only parts and gives no hint that the browser draws them. It also reads like a low-level system call more than a UI part.
