## Ranking
1. SY (`system`): "drawn by the system" fits the phone and the browser equally well, and it reads naturally on all three targets. A reader would expect a website version to be the browser's own control.
2. OS (`os`): it clearly means "operating system", which fits the phone apps well. On the website it is a stretch, because the browser is not usually called the OS, so a reader may expect it to be phone-only. It is also a terse abbreviation.
3. NT (`native`): in cross-platform frameworks, "native" usually means the phone's own UI as opposed to web views, as in React Native. That pushes a reader to expect nothing on the website, or a fake stand-in there.

B: SY: yes, likely, since a browser counts as a system that draws its own controls. OS: can't tell; it leans toward phone-only. NT: can't tell; it leans toward "no" or "only an emulation".

C: SY: somewhat. Many design systems are named "System" or "X System", and `system.button` could read as a library's styled set. OS: somewhat. It is short enough to be a brand or theme name, but "operating system" is the dominant reading. NT: somewhat. Names like "native" libraries or "NativeBase" exist, so it could read as a component kit for mobile.

D: Mostly the phone's own UI. "Native" in an app built for iPhone, Android and the web strongly suggests the iOS or Android control. "Native HTML element" is a real usage too, so after a moment's thought it can also mean the browser's built-in element. On a first read, though, a reader would not assume it means both.
