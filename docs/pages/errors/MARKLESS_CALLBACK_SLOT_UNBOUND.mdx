# MARKLESS_CALLBACK_SLOT_UNBOUND

A callback slot is invoked but no component fills it

- Package: compiler

## Message

shared() "…" invokes its "…" callback slot, but no component in this module assigns a callback prop into it.

## Why

Without an assignment there is no widget root to route the call to, so the invocation can never reach a consumer and does nothing at runtime.
