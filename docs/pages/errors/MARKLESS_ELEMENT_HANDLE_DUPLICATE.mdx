# MARKLESS_ELEMENT_HANDLE_DUPLICATE

element() handle is bound more than once

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

Cannot bind element handle "…" inside a keyed repeat because one authored handle would point at many row host elements. markless debugging playbook: run pnpm doctor, or read agent/markless.md in the installed @markless/core package

Cannot bind element handle "…" to multiple live host elements. markless debugging playbook: run pnpm doctor, or read agent/markless.md in the installed @markless/core package

## Why

A resumed element handle declared as a single element must resolve to one current DOM locator. Binding it to multiple live elements would make lazy event code ambiguous.

Each repeated row has its own DOM locator, so one handle declared as a single element cannot say which row it means.
