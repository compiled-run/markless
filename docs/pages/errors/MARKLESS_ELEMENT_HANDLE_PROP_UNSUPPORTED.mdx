## Message

Cannot bind el=\{…\} because this slice only supports element handles passed as direct component props, not through arrays or nested object props.

## Why

Direct prop forwarding has one parent-owned element() handle for one child prop. Array and nested object containers need deeper edge tracking before the compiler can prove the owning handle.
