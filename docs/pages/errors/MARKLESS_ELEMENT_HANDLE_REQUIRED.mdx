# MARKLESS_ELEMENT_HANDLE_REQUIRED

el expects an element() handle

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

Cannot bind el=\{…\} because "…" is …, not an element() handle.

## Why

DOM elements are host resources. el can only bind element() handles so resume can recover the current DOM locator without serializing a DOM node.
