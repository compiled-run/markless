# MARKLESS_EVENT_SPREAD_UNSUPPORTED

Event handlers cannot be spread onto an element

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

\{...…\} spreads … onto an element. Events compile to static view records, so handlers inside a spread would be discarded.

## Why

The compiler owns event discovery so the browser can resume without scanning markup; a runtime spread hides which events exist from the compiler.
