# MARKLESS_REPEAT_BINDING_NAME_CONFLICT

Two @for loops give the same name two different meanings

- Package: compiler
- Pass or phase: public-render
- Severity: error

## Message

"…" is one @for loop's item and another @for loop's index in the same file. Rename one of them.

## Why

Every @for expression in a file is compiled into readers that share one set of row bindings, so a name can bind to the row item or the row index, never to both.
