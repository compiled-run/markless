# MARKLESS_STATE_CONST_REASSIGNMENT

Cannot reassign a const graph binding

- Package: compiler
- Pass or phase: state-lowering
- Severity: error

## Message

Cannot update "…" because it was declared with const. JavaScript const binding semantics are preserved for state().

## Why

state() removes marker syntax, but it does not change JavaScript binding rules. A const binding cannot be reassigned during resume or initial render.
