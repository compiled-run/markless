# MARKLESS_STATE_WRITE_IN_COMPUTED

A computed cannot write graph state

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

`…` writes to `…` while deriving a computed value. A computed is a graph read, so writing graph state there would re-trigger the same derivation.

## Why

A computed is a demand-driven read in the graph; the only effects in the system are compiler-generated DOM updates, so a write inside a derive is a self-waking cycle that cannot resume.
