# MARKLESS_STYLE_OBJECT_UNSUPPORTED

This style object shape is not supported

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

style=\{…\} uses …, which style objects do not support. Supported: an object literal written on the element, or an unmodified same-file `const` object literal referenced by name or flattened with `...spread`, with keys that are plain names or compile-time strings and values that are literals, state, computed values, or props.

## Why

A style object is turned into CSS text while compiling, so every key must be readable from the source and every value must be one the compiler can recombine into the same text the server renders and the browser rewrites. Objects that are imported, held in state, mutated, aliased, or built at runtime cannot be frozen that way.
