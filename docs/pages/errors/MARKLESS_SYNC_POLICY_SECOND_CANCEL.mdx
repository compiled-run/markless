# MARKLESS_SYNC_POLICY_SECOND_CANCEL

Only one cancel statement becomes the synchronous event policy

- Package: compiler
- Pass or phase: semantic-graph
- Severity: error

## Message

This …() for … sits outside the statement the synchronous policy was extracted from, so it would run only after the lazy handler loads and never reach the event.

## Why

The compiler lifts one guarded cancel per handler into the policy the resumer applies before the handler symbol loads; every other cancel stays in the lazy handler, where the event has already finished dispatching.
