## Mechanism implemented for the experiment

- Route ownership groups related compiler artifacts and transitive module dependencies into native ESM packs; shared dependencies currently enter one conservative shared pack.
- `strictExecutionOrder` retains Rolldown's deferred initialization. A generated lazy facade is collapsed only for the supported named-import/initializer/named-export shape. A pack exports a namespace getter that initializes that original module on demand, preserves live getters and namespace identity, and retains initialization failures.
- Compiler symbol resolver modules optionally emit literal lazy imports keyed by symbol identity. URL compaction must not change which logical module is loaded.
- Bundler experimental transforms avoid redundant emitted symbol/resolver roots. The default delivery path remains unchanged.
- Router preload traversal handles static cycles and excludes foreign route-owned chunks. Current-route SSR preload maps contain five URLs on the inspected docs routes.
- Intent-mode destination loading replaces eager preloads for rendered sidebar links with modulepreload hints on pointerover, focusin, or pointerdown. Client navigation installs document delegation for replacement route controls. Initial current-route preloads remain eager.

The ordinary docs config now enables native packing by default; `website/vite.native-packs.config.ts` delegates to it. The last completed build before intent loading had 63 JS files across the docs site; 1,775 tiny lazy facades were removed. The subsequent intent-mode Chrome run confirmed five framework JS requests plus three website-owned scripts per tested route.
