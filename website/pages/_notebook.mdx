# Two notebooks

A scratch page that compares two ways to draw the Code block.

## Drawn in CSS

<Code note="Click Count a few times, and the roll stays put. Then change the 6 to 100.">
```tsrx title="rolled-once.tsrx"
import { state } from '@markless/core';

export default function RolledOnce() @{
	let count = state(0);
	const roll =
		Math.floor(Math.random() * 6) + 1;

	<section>
		<p>Rolled at setup: {roll}</p>
		<button onClick={() => count++}>
			Count {count}
		</button>
	</section>
}
```
</Code>
