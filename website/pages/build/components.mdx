# Components and props

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="A component is a function that returns elements, and props are the values you hand it." terms="component elements" />

```tsrx title="welcome.tsrx"
function NameTag({ name }: { name: string }) @{
	<p>Hello, {name}</p>
}

export default function Welcome() @{
	<NameTag name="Ada" />
}
```

**`NameTag`** is a component: you place it with `<NameTag />`. **`name="Ada"`** is a *prop*, and `{ name }` receives it, so the page shows `Hello, Ada`.

## A prop is a live read

A child runs once, and its props keep reading the parent's current value.

- The parent changes its state.
- Every child that reads it shows the new value.
- No child is placed again.

Drag a few `Avatar` stickers onto the page, then turn its `name` selector.

<Code steps={[{ label: 'Press Grace. The greeting changes, and the tag number stays.', shows: 'Hello, Grace' }, { label: 'Under the tag, add `<NameTag name={name.toUpperCase()} />`. Press Linus, and both follow `name`.', source: 'name={name.toUpperCase()}' }]}>
```tsrx title="profile.tsrx"
import { state } from '@markless/core';

function NameTag({ name }: { name: string }) @{
	const ticket =
		Math.floor(Math.random() * 900) + 100;

	<div>
		<p>Hello, {name}</p>
		<p>Tag #{ticket}</p>
	</div>
}

export default function Profile() @{
	let name = state('Ada');

	<section>
		<NameTag name={name} />
		<button onClick={() => (name = 'Grace')}>
			Grace
		</button>
		<button onClick={() => (name = 'Linus')}>
			Linus
		</button>
	</section>
}
```
</Code>

## A callback talks back

A child can't change the parent's state. The parent hands it a *callback*: a function the child calls.

<Code steps={[{ label: 'Press Grace.', shows: 'Host: Grace' }, { label: 'Add a third guest, `<Guest name="Linus" onPick={choose} />`, and press it.', shows: 'Host: Linus' }]}>
```tsrx title="host-pick.tsrx"
import { state } from '@markless/core';

type GuestProps = {
	name: string;
	onPick: (name: string) => void;
};

function Guest({ name, onPick }: GuestProps) @{
	<button onClick={() => onPick(name)}>
		{name}
	</button>
}

export default function HostPick() @{
	let host = state('nobody');
	const choose = (name: string) => (host = name);

	<section>
		<p>Host: {host}</p>
		<Guest name="Ada" onPick={choose} />
		<Guest name="Grace" onPick={choose} />
	</section>
}
```
</Code>

## Children go where you put them

Elements between a component's tags arrive as its `children` prop, typed `Children`.

<Code steps={[{ label: 'Inside `Card`, under the first line, add `<p>Free delivery</p>`.', shows: 'Free delivery' }, { label: 'Wrap `{children}` in `<div class="inner">` and `</div>`. Both lines still show.', source: '<div class="inner">{children}</div>' }]}>
```tsrx title="card.tsrx"
import type { Children } from '@markless/core';

type CardProps = { children?: Children };

function Card({ children }: CardProps) @{
	<section class="card">{children}</section>
}

export default function Shop() @{
	<Card>
		<p>Fresh beans every Monday</p>
	</Card>
}
```
</Code>

Not yet:

- A callback prop takes zero parameters or one (`MARKLESS_CALLBACK_PROP_ARITY_UNSUPPORTED`). Pass one object instead.
- You can place, wrap or pass on `children`, but not map, count or index it (`MARKLESS_CHILDREN_OPAQUE`).
- A default like `{ text = 'none' }` that the elements show stops the build (`MARKLESS_STATE_DESTRUCTURE_DEFAULT_UNSUPPORTED`). Write `computed(() => text ?? 'none')` instead.

When a handler needs the real `<input>`, [reach a real element](/build/elements).
