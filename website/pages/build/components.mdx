# Props pass values down, and callbacks talk back

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="A component is a function, and its props are its parameter. A prop is a live read of the parent's value, not a copy." />

<Code steps={[{ label: 'Press Add a bag three times. The bag count goes up, and the ticket number stays.', shows: '3' }, { label: 'Under the badge, add `<CartBadge bags={bags * 2} />`. Press again, and both badges follow `bags`.', source: 'bags={bags * 2}' }]}>
```tsrx title="cart.tsrx"
import { state } from '@markless/core';

function CartBadge({ bags }: { bags: number }) @{
	const ticket =
		Math.floor(Math.random() * 900) + 100;

	<p>
		<strong>{bags}</strong> bags in the cart.
		Badge #{ticket}
	</p>
}

export default function Cart() @{
	let bags = state(0);

	<section>
		<CartBadge bags={bags} />
		<button onClick={() => bags++}>
			Add a bag
		</button>
	</section>
}
```
</Code>

`CartBadge` takes `{ bags }`, and the parent writes `bags={bags}`. That is the whole connection.

## Talk back with a callback

A child can't change the parent's state. The parent hands it a function, and the child calls it.

<Code steps={[{ label: 'Press Grace.', shows: 'Host: Grace' }, { label: 'Add a third guest, `<Guest name="Linus" onPick={choose} />`, and press it.', shows: 'Host: Linus' }]}>
```tsrx title="host-pick.tsrx"
import { state } from '@markless/core';

type GuestProps = {
	name: string;
	onPick: (name: string) => void;
};

function Guest({ name, onPick }: GuestProps) @{
	<button onClick={() => onPick(name)}>
		{name}
	</button>
}

export default function HostPick() @{
	let host = state('nobody');
	const choose = (name: string) => (host = name);

	<section>
		<p>Host: {host}</p>
		<Guest name="Ada" onPick={choose} />
		<Guest name="Grace" onPick={choose} />
	</section>
}
```
</Code>

## Put children where you want them

Elements between a component's tags arrive as `children`, typed `Children` from `@markless/core`.

```tsrx title="card.tsrx"
import type { Children } from '@markless/core';

export default function Card({ children }: { children?: Children }) @{
	<section class="card">{children}</section>
}
```

Not yet:

- A callback prop takes zero parameters or one (`MARKLESS_CALLBACK_PROP_ARITY_UNSUPPORTED`). Pass one object instead.
- You can place, wrap or pass on `children`, but not map, count or index it (`MARKLESS_CHILDREN_OPAQUE`).
- A default like `{ text = 'none' }` that the elements show stops the build (`MARKLESS_STATE_DESTRUCTURE_DEFAULT_UNSUPPORTED`). Write `computed(() => text ?? 'none')` instead.

When a handler needs the real `<input>`, [reach a real element](/build/elements).
