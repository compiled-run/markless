# Props pass values down, and callbacks talk back

<PageMeta time="3 min" assumes="state, events" />

<Subtitle text="A component is a function, and its props are its parameter. A prop is a live read of the parent's value, not a copy." />

Press **Add a bag** a few times.

<Code steps={[{ label: 'Press Add a bag three times. The bag count goes up, and the ticket number stays.', shows: '3' }, { label: 'Under the badge, add `<CartBadge bags={bags * 2} />`. Press again, and both badges follow `bags`.', source: 'bags={bags * 2}' }]}>
```tsrx title="cart.tsrx"
import { state } from '@markless/core';

function CartBadge({ bags }: { bags: number }) @{
	const ticket =
		Math.floor(Math.random() * 900) + 100;

	<p>
		<strong>{bags}</strong> bags in the cart.
		Badge #{ticket}
	</p>
}

export default function Cart() @{
	let bags = state(0);

	<section>
		<CartBadge bags={bags} />
		<button onClick={() => bags++}>
			Add a bag
		</button>
	</section>
}
```
</Code>

`CartBadge` takes `{ bags }`, and the parent writes `bags={bags}`. That is the whole connection.

`CartBadge` picks its ticket number once, when it runs to set up the page. A click changes `bags`, and only the text inside `<strong>` changes. The child never runs again.

## Talk back with a callback

A child can't change the parent's state itself. The parent hands it a function, and the child calls that function.

<Code steps={[{ label: 'Press Grace.', shows: 'Host: Grace' }, { label: 'Add a third guest, `<Guest name="Linus" onPick={choose} />`, and press it.', shows: 'Host: Linus' }]}>
```tsrx title="host-pick.tsrx"
import { state } from '@markless/core';

type GuestProps = {
	name: string;
	onPick: (name: string) => void;
};

function Guest({ name, onPick }: GuestProps) @{
	<button onClick={() => onPick(name)}>
		{name}
	</button>
}

export default function HostPick() @{
	let host = state('nobody');
	const choose = (name: string) => (host = name);

	<section>
		<p>Host: {host}</p>
		<Guest name="Ada" onPick={choose} />
		<Guest name="Grace" onPick={choose} />
	</section>
}
```
</Code>

Each `Guest` gets its own `name` and the same `onPick`, the parent's `choose`. The click runs `onPick(name)` in the child, and `choose` sets `host`.

## Put children where you want them

Elements between a component's tags arrive as its `children` prop. Write `{children}` where they go. The type is `Children` from `@markless/core`.

```tsrx title="welcome.tsrx"
import type { Children } from '@markless/core';

function Card({ title, children }: { title: string; children?: Children }) @{
	<section class="card">
		<h2>{title}</h2>
		{children}
	</section>
}

export default function Welcome() @{
	<Card title="Welcome">
		<p>This paragraph lands where Card writes children.</p>
	</Card>
}
```

## Work out a default with `computed()`

A default in the parameter, like `{ text = 'none' }`, stops the build when your elements show that prop. The error is `MARKLESS_STATE_DESTRUCTURE_DEFAULT_UNSUPPORTED`. Work out the fallback in a computed value instead:

```tsrx title="label.tsrx"
import { computed } from '@markless/core';

export default function Label({ text }: { text?: string }) @{
	const shown = computed(() => text ?? 'none');

	<p>{shown}</p>
}
```

Not yet:

- A callback prop takes zero parameters or one. Two stop the build with `MARKLESS_CALLBACK_PROP_ARITY_UNSUPPORTED`, so pass one object, like `onPick({ first, last })`.
- You can place `children`, wrap it, or pass it on, but not map, count or index it. That stops the build with `MARKLESS_CHILDREN_OPAQUE`.
