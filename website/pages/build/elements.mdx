# Reach a real element with `element()`

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="A handle is a name for one real element. A handler can use it once that element is on the page." />

<Code steps={[{ label: 'Press Add guest. The count goes up, and the cursor lands back in the field.', shows: 'Guests added: 1' }, { label: "Empty the field on each press: above `field?.focus()`, add `if (field) field.value = '';`.", source: "field.value = ''" }]}>
```tsrx title="guest-form.tsrx"
import { element, state } from '@markless/core';

export default function GuestForm() @{
	let added = state(0);
	const field = element<HTMLInputElement>();

	<section>
		<label for={field}>Guest name</label>
		<input el={field} />
		<button
			onClick={() => {
				added++;
				field?.focus();
			}}
		>
			Add guest
		</button>
		<p>Guests added: {added}</p>
	</section>
}
```
</Code>

`el={field}` binds the handle to the `<input>`. In a handler, `field` is that element, or `undefined` if it isn't on the page, hence `field?.focus()`.

## A handle is a ticket

Hand the ticket over: press it, drag it right, or press Enter.

<CoatAnatomy />

The component gets its ticket before the field exists. A handler hands it in and gets the real `<input>`, or `undefined` if the field has left the page.

## Point a label at a field without an id

`for={field}` points the label at the field, so pressing **Guest name** puts the cursor there. Markless writes one id on both elements. A handle works the same in `aria-labelledby`, `aria-describedby`, `aria-controls` and `popovertarget`.

## Run setup code with `attach`

`attach` hands the element to your function, for an observer or an outside library. Return a function, and Markless calls it when the element leaves.

```tsrx
<canvas attach={(canvas) => drawChart(canvas)} onVisible={() => {}} />
```

On a server-rendered page, `attach` starts at the first of these:

- a handler like `onClick`, on the element or inside it, just before it first runs
- `onVisible`, when the element scrolls into view
- `onIdle`, once the page has loaded and the browser is idle

An element the browser creates later, like the inside of an `@if`, runs `attach` straight away.

Keep in mind:

- `element<HTMLLIElement[]>()` collects every element bound to it, in page order. A single handle binds one element (`MARKLESS_ELEMENT_HANDLE_DUPLICATE`).
- `attach` goes on page elements, not components (`MARKLESS_ATTACH_HOST_ELEMENT_REQUIRED`), and needs one of the three starters ([`MARKLESS_ATTACH_NO_START_TRIGGER`](/errors/MARKLESS_ATTACH_NO_START_TRIGGER)).
- A handle can't be shown in the elements: `{field.value}` stops the build (`MARKLESS_ELEMENT_HANDLE_RENDER_READ`). Keep that text in `state()`.

Some values should outlive a reload. [Keep them with `storage()`](/build/storage).
