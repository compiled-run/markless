# Element handles

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="A handle is a name for one real element on the page." terms="handle" />

```tsrx title="search-box.tsrx"
import { element } from '@markless/core';

export default function SearchBox() @{
	const field = element<HTMLInputElement>();

	<input el={field} type="search" />
}
```

**`element()`** makes the handle `field`. **`el={field}`** binds it to the `<input>`, so a handler can reach that input.

## Reach the real element

A *handle* is not a copy: in a handler, `field` is the element itself, or `undefined` if it isn't on the page.

- `field?.focus()` puts the cursor in the real input.
- The `?.` covers the moment the input is gone.

Press **Focus search**, then type, then flip the switch and press again.

## A handle links elements without an id

Pass a handle where HTML wants an id, and Markless writes one id on both elements. It works in:

- `for`, so pressing the label focuses the field
- `aria-labelledby`, `aria-describedby` and `aria-controls`
- `popovertarget`

```tsrx title="email-field.tsrx"
import { element } from '@markless/core';

export default function EmailField() @{
	const email = element<HTMLInputElement>();
	const hint = element<HTMLParagraphElement>();

	<section>
		<label for={email}>Email</label>
		<input el={email} aria-describedby={hint} />
		<p el={hint}>We never share it.</p>
	</section>
}
```

## `attach` runs setup code on the element

`attach` hands the element to your function, for an observer or an outside library. Return a function, and Markless calls it when the element leaves.

```tsrx
<canvas attach={(canvas) => drawChart(canvas)} onVisible={() => {}} />
```

On a server-rendered page, `attach` starts at the first of these:

- a handler like `onClick` on the element or inside it, just before it runs
- `onVisible`, when the element scrolls into view
- `onIdle`, once the page has loaded and the browser is idle

Keep in mind:

- `element<HTMLLIElement[]>()` collects every element bound to it, in page order. A single handle binds one element (`MARKLESS_ELEMENT_HANDLE_DUPLICATE`).
- `attach` goes on page elements, not components (`MARKLESS_ATTACH_HOST_ELEMENT_REQUIRED`), and needs one of the three starters ([`MARKLESS_ATTACH_NO_START_TRIGGER`](/errors/MARKLESS_ATTACH_NO_START_TRIGGER)).
- A handle can't be shown in the elements: `{field.value}` stops the build (`MARKLESS_ELEMENT_HANDLE_RENDER_READ`). Keep that text in `state()`.

Some values should outlive a reload. [Keep them with `storage()`](/build/storage).
