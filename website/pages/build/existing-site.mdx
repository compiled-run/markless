# Add Markless to an existing site

<PageMeta level="Building" time="3 min" assumes="state, events" sprite="square" />

<ThemeToggle />

Starting fresh? [Your first app](/start/first-app) is quicker. This page is for when the page already exists, and you want one interactive part on it: a cart button, a calculator, a live search.

You give Markless one empty element, and it fills that element with your component. The rest of the page stays as it is. There is no router and no server, and the build is a folder of static files.

In your site's folder, install Markless and Vite, the tool that builds the page:

<PmCommand add="@markless/core vite" />

## Cut one spot

Your page stays your page. `render(App, { target })` runs your component once and puts what it made inside `target`, the one element you hand it. Nothing outside that element changes.

Press the drawing to drop the like button into its spot, then press again to like it.

## Three files

**`index.html`** is your page. Add two lines where the component should go: an empty `div`, which is the box, and a `script` tag that loads `main.ts`.

```html
<!doctype html>
<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>Beanshop</title>
	</head>
	<body>
		<h1>Beanshop</h1>
		<div id="app"></div>
		<script type="module" src="/src/main.ts"></script>
	</body>
</html>
```

**`src/App.tsrx`** is the component: a button that counts its clicks.

```tsrx
import { state } from '@markless/core';

export default function App() @{
	let count = state(0);

	<button onClick={() => count++}>Count {count}</button>
}
```

**`src/main.ts`** finds the box and hands it to `render()`.

```ts
import { render } from '@markless/core';
import App from './App.tsrx';

const target = document.querySelector('#app');
if (!target) throw new Error('Missing #app');

await render(App, { target });
```

Two small config files finish the folder. Copy them as they are:

<Collapsible sprite="square" summary="package.json and vite.config.ts">

`package.json` names the three commands you will run. Keep the `dependencies` the install added.

```json
{
	"name": "beanshop",
	"private": true,
	"type": "module",
	"scripts": {
		"dev": "vite",
		"build": "vite build",
		"preview": "vite preview"
	}
}
```

`vite.config.ts` adds the `markless()` plugin, which lets Vite read `.tsrx` files.

```ts
import { markless } from '@markless/core/vite';
import { defineConfig } from 'vite';

export default defineConfig({
	plugins: [markless()],
});
```

## Run it

<PmCommand run="dev" />

Open `http://localhost:5173`. You see the **Beanshop** heading and a **Count 0** button under it. Click the button: the number goes up, and the heading never changes. The first time you open the page, Vite may reload it once while it gets Markless ready.

## Ship it

<PmCommand run="build" />

The `dist/` folder now holds `index.html` and a `build/` folder of JavaScript files. Upload `dist/` to any static file host. To try the built page on your machine first, run the `preview` script.

The page has to come from a web server, even a local one. Open `dist/index.html` straight from your disk and the button never appears, because browsers do not load these scripts from files on disk.

For this counter, with `@markless/core` 0.4.0, the browser downloads about 56 KB of compressed JavaScript. About 13 KB of it runs when the page loads. The rest waits until something on the page needs it.

## More than one box

Hand out as many boxes as you like. Each `render()` call fills its own element, and each component keeps its own state.

```html
<div id="app"></div>
<p>Free shipping on orders over $40.</p>
<div id="cart"></div>
```

```ts
await render(App, { target: document.querySelector('#app')! });
await render(Cart, { target: document.querySelector('#cart')! });
```

## Good to know

**`render()` replaces what is inside the box.** A placeholder such as `<p>Loading…</p>` inside `#app` is fine: the component takes its place. Hand it `document.body` and it replaces the whole page.

**There is no script-tag version.** The build turns `.tsrx` files into JavaScript, so a Markless page always goes through Vite.

## Set up your editor

Your editor needs the Markless TypeScript plugin to read `.tsrx` files. Install it with TypeScript:

<PmCommand devAdd="@markless/typescript-plugin typescript" />

Then add this `tsconfig.json` next to `package.json`:

```json
{
	"tsrx": { "compiler": "@markless/typescript-plugin/volar" },
	"compilerOptions": {
		"target": "ES2023",
		"module": "ESNext",
		"moduleResolution": "Bundler",
		"jsx": "preserve",
		"strict": true,
		"types": ["vite/client"],
		"plugins": [{ "name": "@markless/typescript-plugin" }]
	},
	"include": ["src", "vite.config.ts"]
}
```

In 0.4.0 the editor underlines the `render(App, { target })` line in `main.ts` with two type errors. The page still builds and runs correctly; the types are wrong, not the code.
