# Shared state

<PageMeta time="3 min" assumes="state, components" />

<Subtitle text="shared() is state with a name: every component that calls the name gets the same copy." terms="shared state" />

```tsrx title="player.tsrx"
import { shared, state } from '@markless/core';

export const player = shared(() => {
	const box = state({ track: 'Harbour Lights' });
	return { ...box };
});
```

**`shared()`** takes a function that makes the state, and names it `player`. Every component that calls **`player()`** gets the same `track`, with no props in between.

## Two components read one copy

A *shared definition* is the function you pass to `shared()`. Call it from any component, and:

- every caller reads the same values
- a change in one caller shows in all of them
- no prop has to carry it

```tsrx title="player.tsrx"
import { shared, state } from '@markless/core';

export const player = shared(
	() => {
		const box = state({
			track: 'Harbour Lights',
			playing: false,
		});
		return {
			...box,
			toggle() {
				box.playing = !box.playing;
			},
		};
	},
	{ scope: 'page' },
);

function MiniPlayer() @{
	const p = player();

	<p>
		{p.playing ? 'Playing' : 'Paused'}: {p.track}
	</p>
}

export default function NowPlaying() @{
	const p = player();

	<section>
		<MiniPlayer />
		<h2>{p.track}</h2>
		<button onClick={() => p.toggle()}>
			{p.playing ? 'Pause' : 'Play'}
		</button>
	</section>
}
```

## The scope picks who shares a copy

The second argument is the *scope*: who shares one copy.

| Scope | Who shares one copy |
| --- | --- |
| `'page'`, the default | every component on the page |
| `'request'` | the same as `'page'` in the browser |
| `'container'` | one Markless app on the page |
| `'widget'` | the pieces of one rendered widget |

A widget is the first component that calls the definition, plus everything inside it. The volume knobs above are `'widget'`, and so are the [UI components](/ui), so two menus open and close on their own.

## A copy lasts until a reload

- On the server, every request starts from the starting values.
- In the browser, one copy lives as long as the document, through links, Back and Forward.
- A reload starts again from the starting values.

## Two apps on one page share by name

Two separately built apps on one page that call the same definition read and write one copy. The name is the file plus its export, like `lib/player.tsrx#player`, so both must import it from the same place.

Not yet:

- If one app's value has a different shape, it keeps its own copy and logs `MARKLESS_SHARED_SHAPE_MISMATCH`.
- Two components in one file calling a definition with no scope get the warning `MARKLESS_SHARED_FAMILY_SCOPE_IMPLICIT`. Write the scope you mean.
- From another file, `p.toggle()` can stop the build with `MARKLESS_SHARED_METHOD_CROSS_MODULE`. Change the field instead: `p.playing = true`.

Use `state()` when one component owns a value, and `shared()` when several need it. Next, [turn files into pages](/router/pages).
