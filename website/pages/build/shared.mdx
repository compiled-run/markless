# Share one piece of state with `shared()`

<PageMeta level="Building" time="5 min" assumes="state, components" sprite="spiral" />

<ThemeToggle />

A badge and a button live in two components. Both need the same `count`. You can pass it down as a
prop, and pass a callback back up. That works, until five components want it.

`shared()` gives the state a name instead. You define it once. Each component that calls the
definition gets the same `count`, and a change from one shows up in the other.

Click **Add one**.

<SharedCounterDemo />

The click runs in `SharedCounter`, but the number changes inside `Badge`. No prop connects them.

```tsrx
import { shared, state } from '@markless/core';

export const counter = shared(
	() => {
		const box = state({ count: 0 });
		return { ...box, increment() { box.count++; } };
	},
	{ scope: 'page' },
);

function Badge() @{
	const c = counter();

	<output>{c.count}</output>
}

export default function SharedCounter() @{
	const c = counter();

	<section>
		<p>Badge shows: <Badge /></p>
		<button onClick={() => c.increment()}>Add one</button>
	</section>
}
```

The function you pass to `shared()` creates the state. It returns the state plus any methods you
want, like `increment()`. Each component calls `counter()` to get it.

## Who gets the same copy

The second argument picks who shares one copy. There are two choices.

| Scope | Who shares one copy |
| --- | --- |
| `{ scope: 'page' }` | every component on the page that calls the definition |
| `{ scope: 'widget' }` | the pieces inside one rendered widget, like one menu |

A widget is the first component that calls the definition, plus everything you put inside it. Here
are two tallies, each a `Tally` with a `Badge` inside. With `'page'`, they share one copy. Click
either button:

<TalliesPageDemo />

Both numbers move together. Now the same files with `'widget'`:

<TalliesWidgetDemo />

Each tally keeps its own number. Inside one tally, the button and the badge still share.

The pieces live in one file, `tally.tsrx`:

```tsrx
import type { Children } from '@markless/core';
import { shared, state } from '@markless/core';

export const tally = shared(
	() => {
		const box = state({ count: 0 });
		return { ...box, increment() { box.count++; } };
	},
	{ scope: 'widget' },
);

export function Tally({ label, children }: { label: string; children?: Children }) @{
	const t = tally();

	<p>
		{label}: {children} <button onClick={() => t.increment()}>Add one</button>
	</p>
}

export function Badge() @{
	const t = tally();

	<output>{t.count}</output>
}
```

And a second file puts two of them on the page:

```tsrx
import * as tally from './tally.tsrx';

export default function Tallies() @{
	<section>
		<tally.Tally label="Left"><tally.Badge /></tally.Tally>
		<tally.Tally label="Right"><tally.Badge /></tally.Tally>
	</section>
}
```

The [UI components](/ui) use `'widget'`. That is how two menus on one page each stay open or closed
on their own.

<Callout
	sprite="speech-bubble"
	title="Why do I get a missing-scope warning?"
	text="If two components in one file call the same definition and you gave no scope, Markless warns with MARKLESS_SHARED_FAMILY_SCOPE_IMPLICIT. With no scope, the copy is shared across the page. Write { scope: 'widget' } for one copy per widget, or { scope: 'page' } to say you meant it."
/>

<Callout
	sprite="cross"
	title="Can I call a method from another file?"
	text="Keep the definition and the components that call its methods in one file, as these examples do. From another file, a call like c.increment() can stop the build with MARKLESS_SHARED_METHOD_CROSS_MODULE. In that file, change the field directly instead: c.count++."
/>

Use `state()` when one component owns the value. Use `shared()` when several components need it.
