# Share one piece of state with `shared()`

<PageMeta time="3 min" assumes="state, components" />

<Subtitle text="shared() gives state a name. Every component that calls the name gets the same value, with no props in between." />

<Code steps={[{ label: 'Press Add to cart. The click runs in Shop, and the badge in CartBadge changes.', shows: 'Bags in the cart: 1' }, { label: 'Add a `remove()` method that runs `box.bags--`, and a button in `Shop` that calls it.', source: 'box.bags--' }]}>
```tsrx title="cart.tsrx"
import { shared, state } from '@markless/core';

export const cart = shared(
	() => {
		const box = state({ bags: 0 });
		return {
			...box,
			add() {
				box.bags++;
			},
		};
	},
	{ scope: 'page' },
);

function CartBadge() @{
	const c = cart();

	<p>Bags in the cart: {c.bags}</p>
}

export default function Shop() @{
	const c = cart();

	<section>
		<CartBadge />
		<button onClick={() => c.add()}>
			Add to cart
		</button>
	</section>
}
```
</Code>

No prop connects `Shop` and `CartBadge`. Both call `cart()`, so both get the same `bags`.

## Pick who shares one copy

The second argument to `shared()` picks who shares a copy. Press each stall's **Sell one**.

<BakeSaleDemo />

The day total is `'page'`, so every stall moves it. Each stall's count is `'widget'`, so it's its own.

| Scope | Who shares one copy |
| --- | --- |
| `'page'`, the default | every component on the page |
| `'request'` | the same as `'page'` in the browser |
| `'container'` | one Markless app on the page |
| `'widget'` | the pieces of one rendered widget, like one menu |

A widget is the first component that calls the definition, plus everything inside it. The [UI components](/ui) use `'widget'`, so two menus open and close on their own.

## It lasts while the reader browses

- **On the server**, every request starts from the starting values.
- **In the browser**, one copy lives as long as the document, through links, Back and Forward.
- **A reload** starts again from the starting values.

## Two apps on one page share by name

When two separately built apps on one page call the same definition, they read and write one copy. The name is the definition's file plus its export, like `lib/cart.tsrx#cart`, so both must import it from the same place. If the value's shape differs, that app keeps its own copy and logs `MARKLESS_SHARED_SHAPE_MISMATCH`.

Keep in mind:

- Two components in one file calling a definition with no scope get the warning `MARKLESS_SHARED_FAMILY_SCOPE_IMPLICIT`. Write the scope you mean.
- Call a definition's methods from the file that defines it. From another file, `c.add()` can stop the build with `MARKLESS_SHARED_METHOD_CROSS_MODULE`; change the field instead, `c.bags++`.

Use `state()` when one component owns a value, and `shared()` when several need it. Next, [turn files into pages](/router/pages).
