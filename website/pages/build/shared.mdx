<Subtitle text="shared() gives state a name. Every component that calls the name gets the same value, with no props in between." />

<Code steps={[{ label: 'Press Add to cart. The click runs in Shop, and the badge in CartBadge changes.', shows: 'Bags in the cart: 1' }, { label: 'Add a `remove()` method that runs `box.bags--`, and a button in `Shop` that calls it.', source: 'box.bags--' }]}>
```tsrx title="cart.tsrx"
import { shared, state } from '@markless/core';

export const cart = shared(
	() => {
		const box = state({ bags: 0 });
		return {
			...box,
			add() {
				box.bags++;
			},
		};
	},
	{ scope: 'page' },
);

function CartBadge() @{
	const c = cart();

	<p>Bags in the cart: {c.bags}</p>
}

export default function Shop() @{
	const c = cart();

	<section>
		<CartBadge />
		<button onClick={() => c.add()}>
			Add to cart
		</button>
	</section>
}
```
</Code>

No prop connects `Shop` and `CartBadge`. Both call `cart()`, and both get the same `bags`.

The function you pass to `shared()` makes the state. It returns that state plus any methods you want, like `add()`.

## Pick who shares one copy

The second argument says who shares a copy. Press each stall's **Sell one**, and watch which numbers move.

<Code steps={[{ label: 'Press Sell one under Lemonade twice. The day total and Lemonade move, and Cookies stays at 0.', shows: 'Sold today: 2' }, { label: "In `stall`, change `'widget'` to `'page'`. Press Sell one under Lemonade, and Cookies moves too.", shows: 'Cookies: 1 sold' }]}>
```tsrx title="bake-sale.tsrx"
import { shared, state } from '@markless/core';

const day = shared(
	() => {
		const box = state({ sold: 0 });
		return { ...box };
	},
	{ scope: 'page' },
);

const stall = shared(
	() => {
		const box = state({ sold: 0 });
		return { ...box };
	},
	{ scope: 'widget' },
);

function Stall({ name }: { name: string }) @{
	const s = stall();
	const d = day();

	<p>
		<span>{name}: {s.sold} sold</span>
		<button
			onClick={() => {
				s.sold++;
				d.sold++;
			}}
		>
			Sell one
		</button>
	</p>
}

export default function BakeSale() @{
	const d = day();

	<section>
		<h2>Sold today: {d.sold}</h2>
		<Stall name="Lemonade" />
		<Stall name="Cookies" />
	</section>
}
```
</Code>

- The day total moves on every press. `day` says `'page'`, so the whole page shares one copy.
- Each stall's count moves only for its own stall. `stall` says `'widget'`, so each `Stall` gets its own copy.

| Scope | Who shares one copy |
| --- | --- |
| `'page'`, the default | every component on the page |
| `'request'` | the same as `'page'` in the browser |
| `'container'` | one Markless app on the page, not the others |
| `'widget'` | the pieces of one rendered widget, like one menu |

A widget is the first component that calls the definition, plus everything inside it. The [UI components](/ui) use `'widget'`, so two menus on one page open and close on their own.

## It lasts while the reader browses

- **On the server**, every request starts from the starting values. One visitor never sees another's writes.
- **In the browser**, one copy lives as long as the document. A link to another of your pages keeps it, and so do Back and Forward. The next page shows the live value from its first frame.
- **A reload** starts again from the starting values.

## Two apps on one page share by name

Some pages hold more than one Markless app, built and shipped separately. Each such app is called a *micro-frontend*. When two of them call the same definition, they read and write one copy.

The name is the file the definition lives in plus its export name, such as `lib/cart.tsrx#cart`. For a definition from a package, the file is its path under `node_modules/`. So both apps must import the definition from the same place.

The value must also have the same shape in both: the same field names and types. An app whose shape differs keeps its own copy and logs `MARKLESS_SHARED_SHAPE_MISMATCH` once.

Not yet:

- Two components in one file calling a definition with no scope get the warning `MARKLESS_SHARED_FAMILY_SCOPE_IMPLICIT`. Write `{ scope: 'widget' }` for a copy per widget, or `{ scope: 'page' }` to say you meant to share.
- Keep the definition and the components that call its methods in one file. From another file, `c.add()` can stop the build with `MARKLESS_SHARED_METHOD_CROSS_MODULE`; change the field instead, `c.bags++`.

Use `state()` when one component owns a value, and `shared()` when several need it. Next, [turn files into pages](/router/pages).
