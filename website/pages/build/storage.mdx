# Keep a value across reloads with `storage()`

<PageMeta level="Building" time="4 min" assumes="state" sprite="bookmark" />

<ThemeToggle />

Some values belong to the reader, like a theme or a favourite drink. Reload the page, and `state()`
starts over from its first value. The reader's choice is gone.

`storage()` is string state that saves itself in the browser's `localStorage`. You read it and
change it like any other variable. Each change also sets a `data-` attribute on `<html>`, so your
CSS can follow the value.

Pick a drink.

<DrinkPick />

One click changed three things: the highlighted button, the saved value in `localStorage`, and the
`data-docs-drink` attribute on `<html>`. Now reload the page. Your pick keeps its highlight.

```tsrx
import { storage } from '@markless/core';

export default function DrinkPick() @{
	let drink = storage('docs-drink', 'tea');

	<section>
		<button class="tea" onClick={() => (drink = 'tea')}>Tea</button>
		<button class="coffee" onClick={() => (drink = 'coffee')}>Coffee</button>
		<button class="cocoa" onClick={() => (drink = 'cocoa')}>Cocoa</button>
	</section>
}
```

The first argument is the `localStorage` key. The second is the starting value, for a reader who
has not picked yet. With the key `docs-drink`, `<html>` gets `data-docs-drink`.

The highlight is plain CSS that reads that attribute. The demo uses a rule like this one for each
drink:

```css
html[data-docs-drink='coffee'] .coffee {
	background: gold;
}
```

## Style from the attribute

The attribute is the part to style from. A dark theme works the same way:

```tsrx
import { storage } from '@markless/core';

let theme = storage('theme', 'light');

export default function ThemeToggle() @{
	<button onClick={() => (theme = theme === 'light' ? 'dark' : 'light')}>Switch theme</button>
}
```

```css
[data-theme='dark'] body {
	background: #222;
	color: #eee;
}
```

You can call `storage()` at the top of a file, as here. You can also call it inside a component,
as the drink demo does.

When a server renders the page, Markless adds one small script before the page content. It
reads the saved value and sets the `<html>` attribute first. So CSS that uses `data-theme` is right
from the first paint.

## One argument or two

| Call | `localStorage` key | Attribute on `<html>` |
| --- | --- | --- |
| `let theme = storage('theme', 'light')` | `theme` | `data-theme` |
| `let theme = storage('light')` | `markless:theme` | `data-markless-theme` |

With one argument, that argument is the starting value. Markless builds the key from the variable
name.

<Callout
	sprite="cross"
	title="Renaming the variable loses saved values"
	text="With one argument, the key follows the variable name. Rename theme to mode, and every reader's saved choice is left behind under the old key. For anything you ship, pass the key yourself."
/>

<Callout
	sprite="cross"
	title="Why does storage() reject my key?"
	text="The key and the starting value must be written as plain strings, like 'theme'. A key built from other values stops the build with MARKLESS_STORAGE_KEY_STATIC. The value itself is always a string."
/>

Declare it with `let` so you can change it. You can't assign to a `const` storage value.
