# Storage

<PageMeta time="2 min" assumes="state" />

<Subtitle text="storage() is a value the browser keeps for the reader, so a reload doesn't reset it." />

```tsrx title="theme.tsrx"
import { storage } from '@markless/core';

let theme = storage('theme', 'light');

export default function Theme() @{
	<p>Theme: {theme}</p>
}
```

**`storage()`** takes a **key**, `'theme'`, and a **starting value**, `'light'`. You read and write `theme` like any other variable.

## A reload keeps storage(), not state()

A *reload* starts the page over from its code. `state()` starts over with it, and `storage()` doesn't.

- The dark-mode switch is `storage()`: it stays dark.
- The sidebar is `state()`: it closes again.
- Clear the site data, and `storage()` starts over too.

Flip the switch, open the sidebar, then press the reload arrow.

```tsrx title="mode-switch.tsrx"
import { storage } from '@markless/core';

export default function ModeSwitch() @{
	let mode = storage('mode', 'light');

	<button
		onClick={() => {
			mode = mode === 'light' ? 'dark' : 'light';
		}}
	>
		Mode: {mode}
	</button>
}
```

## Each write saves in three places

- a cookie named `markless-theme`, so the server renders the value in the first byte
- `localStorage`, under `theme`
- `data-theme` on `<html>`, for your CSS

A page that shows a `storage()` value answers `Cache-Control: private`, so a shared cache never hands one reader's page to another.

## One argument names the key for you

| Call | Saved under | Attribute on `<html>` |
| --- | --- | --- |
| `storage('theme', 'light')` | `theme` | `data-theme` |
| `storage('light')` | `markless:theme` | `data-markless-theme` |

With one argument, the key comes from the variable name, so renaming the variable loses saved values. Pass the key yourself for anything you ship.

Not yet:

- The key and starting value must be plain strings, or the build stops with `MARKLESS_STORAGE_KEY_STATIC`.
- The value is always a string.
- A `const` storage value is read-only (`MARKLESS_STATE_CONST_REASSIGNMENT`).
- A prerendered page sets the `<html>` attribute from a small script before the content. It covers the page file and, on an `.mdx` page, the components it imports directly.

When several components need one value, [share it with `shared()`](/build/shared).
