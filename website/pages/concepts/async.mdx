# Waiting is a block, not a flag

<PageMeta time="3 min" assumes="state, computed, conditionals" />

<Subtitle text="Give computed() an async recipe, then write three blocks: the answer, the wait and the failure." />

A loading spinner usually needs four variables: the data, a "still loading" flag, an error, and a
rule in your head about which one wins. Only the data is what the page is about.

```tsrx
@try {
	<p>{fact.text}</p>
} @pending {
	<p>Looking it up...</p>
} @catch {
	<p>That mug is not on the shelf.</p>
}
```

- `@try` holds what you show once the value is ready. Read it directly, as in `fact.text`.
- `@pending` holds what you show before the first answer arrives.
- `@catch` holds what you show when the recipe throws or its promise rejects.

Write them in that order. An `@pending` after `@catch` stops the build with
`MARKLESS_ASYNC_ARM_ORDER`.

## Pick a mug

`loadMugFact`, in the `mug-facts.ts` tab, stands in for a `fetch`. It waits 1.5 seconds, and fails
for a mug it doesn't know.

<Code steps={[{ label: 'Press Tall mug, wait, then press Cracked mug. The `@catch` block takes over.', shows: 'That mug is not on the shelf.' }, { label: 'Change the return line to `return { text: (await loadMugFact(mug)) + mug };`. Reading `mug` after the `await` works too.', source: '(await loadMugFact(mug)) + mug' }]}>
```tsrx title="mug-facts.tsrx"
import { computed, state } from '@markless/core';
import { loadMugFact } from './mug-facts.ts';

export default function MugFacts() @{
	let mug = state('');
	const fact = computed(async () => {
		return { text: await loadMugFact(mug) };
	});

	<section>
		<button onClick={() => (mug = 'tall')}>
			Tall mug
		</button>
		<button onClick={() => (mug = 'small')}>
			Small mug
		</button>
		<button onClick={() => (mug = 'cracked')}>
			Cracked mug
		</button>
		@try {
			<p>{fact.text}</p>
		} @pending {
			<p>Looking it up...</p>
		} @catch {
			<p>That mug is not on the shelf.</p>
		}
	</section>
}
```

```ts title="mug-facts.ts"
const facts: Record<string, string> = {
	tall: 'The tall mug holds a big coffee.',
	small: 'The small mug holds one espresso.',
};

export function loadMugFact(
	mug: string,
): Promise<string> {
	if (mug === '') {
		return Promise.resolve('Pick a mug.');
	}
	return new Promise((resolve, reject) => {
		setTimeout(() => {
			const fact = facts[mug];
			if (fact) {
				resolve(fact);
			} else {
				reject(new Error(`No mug called ${mug}`));
			}
		}, 1500);
	});
}
```
</Code>

Each pick runs the recipe again. After the cracked mug, pick another and the page recovers.

## While a new answer loads

- The old answer stays up, and `@pending` returns only after 5 seconds of waiting.
- The element around the block gets `aria-busy="true"`, so you can style it.

Not yet:

- A read of an async value outside `@try` stops the build with `MARKLESS_ASYNC_BOUNDARY_REQUIRED`.
- A lookup keyed by the answer itself, like `shelf[(await loadPick()).id]`, stops the build with `MARKLESS_ASYNC_POST_AWAIT_READ`. Return the answer, and look it up in a second `computed()`.
