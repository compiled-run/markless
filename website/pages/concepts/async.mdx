# Async values

<PageMeta time="2 min" assumes="state, computed, conditionals" />

<Subtitle text="An async computed is a value that arrives later, and @try shows it once it's there." terms="values" />

```tsrx title="forecast.tsrx"
const forecast = computed(async () => loadForecast(city));

@try {
	<p>{forecast.text}</p>
} @pending {
	<p>Checking the sky…</p>
}
```

**`computed(async …)`** makes a value that arrives later. **`@try`** shows it once it's ready, and **`@pending`** holds the spot until then.

## Only the slow spot waits

An *async* value is one that arrives later. It can only be shown inside `@try`, and everything outside `@try` is on the page straight away.

- `@try` holds what you show once the value is ready.
- `@pending` holds what you show before the first answer.
- `@catch` holds what you show if loading it fails. Write the three in that order.

```tsrx title="forecast-card.tsrx"
import { computed, state } from '@markless/core';
import { loadForecast } from './forecast.ts';

export default function ForecastCard() @{
	let city = state('Oslo');
	const forecast = computed(async () => {
		return { text: await loadForecast(city) };
	});

	<section>
		<button onClick={() => (city = 'Oslo')}>
			Oslo
		</button>
		<button onClick={() => (city = 'Lisbon')}>
			Lisbon
		</button>
		<button onClick={() => (city = 'Atlantis')}>
			Atlantis
		</button>
		@try {
			<p>{forecast.text}</p>
		} @pending {
			<p>Checking the sky…</p>
		} @catch {
			<p>No forecast for that city.</p>
		}
	</section>
}
```

```ts title="forecast.ts"
const skies: Record<string, string> = {
	Oslo: 'Oslo: rain, 4°',
	Lisbon: 'Lisbon: sunny, 19°',
};

export function loadForecast(
	city: string,
): Promise<string> {
	return new Promise((resolve, reject) => {
		setTimeout(() => {
			const sky = skies[city];
			if (sky) resolve(sky);
			else reject(new Error(city));
		}, 1200);
	});
}
```

## The old answer stays while a new one loads

Picking again keeps the last answer on the page until the new one lands. The element around the block gets `aria-busy="true"` meanwhile, so you can style the wait.
