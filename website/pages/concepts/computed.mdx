# Computed values

<PageMeta time="2 min" assumes="state" />

<Subtitle text="A computed is one of your values, worked out from other values and kept up to date." terms="computed values" />

```tsrx title="mixer.tsrx"
import { computed, state } from '@markless/core';

export default function Mixer() @{
	let red = state(60);
	let blue = state(40);
	const mix = computed(
		() => `color-mix(in oklab, red ${red}%, blue ${blue}%)`,
	);

	<p style={'background: ' + mix}>Mix</p>
}
```

**`state()`** holds `red` and `blue`. **`computed()`** works out `mix` from them, and works it out again whenever either one changes.

## A computed follows what it reads

The function you pass is the *recipe*. Markless reads it and finds `red` and `blue`, so you never list them.

- Change `red` or `blue`, and `mix` follows.
- Nothing else has to remember to update it.
- You can't set `mix` yourself.

```tsrx title="paint-mixer.tsrx"
import { computed, state } from '@markless/core';

export default function PaintMixer() @{
	let red = state(60);
	let blue = state(40);
	const mix = computed(
		() =>
			`color-mix(in oklab, red ${red}%, ` +
			`blue ${blue}%)`,
	);

	<section>
		<label>
			Red {red}
			<input
				type="range"
				value={red}
				onInput={(event) =>
					(red = Number(
						event.currentTarget.value,
					))
				}
			/>
		</label>
		<label>
			Blue {blue}
			<input
				type="range"
				value={blue}
				onInput={(event) =>
					(blue = Number(
						event.currentTarget.value,
					))
				}
			/>
		</label>
		<p style={'background: ' + mix}>Mix</p>
	</section>
}
```
</Code>

A computed only reads; it never writes. Saving or logging goes in the handler that made the change.

<Collapsible sprite="star-badge" summary="How do existing tools handle this?">

Many tools ask you to list a derived value's inputs in a dependency array, and to run side work in an effect hook. Markless finds the inputs before your app runs, and side work stays in the handler.
