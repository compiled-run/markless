# A hidden branch is not hidden, it is gone

## Keep the value above the branch

<Code steps={[{ label: 'Press Show or hide the note, and type a note longer than 20 letters. The line under it changes.', shows: 'That is a long note.' }, { label: 'Change `20` to `5`, and type six letters.', source: 'note.length > 5' }]}>
```tsrx title="note-panel.tsrx"
import { computed, state } from '@markless/core';

export default function NotePanel() @{
	let open = state(false);
	let note = state('');
	const long = computed(() => note.length > 20);

	<section>
		<button onClick={() => (open = !open)}>
			Show or hide the note
		</button>
		@if (open) {
			<label>
				Note
				<input
					value={note}
					onInput={(event) =>
						(note = event.currentTarget.value)
					}
				/>
			</label>
		}
		@if (long) {
			<p>That is a long note.</p>
		} @else {
			<p>Short and sweet.</p>
		}
	</section>
}
```
</Code>

The field inside the `@if` is rebuilt each time. `note` lives above it, so your text survives. Inside the `@if`, `state()` stops the build with `MARKLESS_STATE_CREATION_SITE_UNSTABLE`.

## `@else` and `@switch`

- `@else` covers the other side. A plain `else` stops the build with `MARKLESS_BRANCH_ELSE_SPELLING`.
- `@switch (status) { @case 'ready': { … } @default: { … } }` picks one case.

Not yet:

- An `@if` or `@switch` can't sit inside another `@if`, and `@else if` doesn't work: `MARKLESS_BRANCH_ARM_UPDATE_UNSUPPORTED`. Put branches side by side, or use `@switch`.
