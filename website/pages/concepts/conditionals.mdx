<Subtitle text="@if puts elements on the page while its test is true, and takes them off again when it isn't." terms="elements" />

```tsrx title="note-field.tsrx"
import { state } from '@markless/core';

export default function NoteField() @{
	let open = state(true);

	@if (open) {
		<textarea placeholder="write here" />
	}
}
```

**`@if (open)`** builds the `<textarea>` while `open` is true. When `open` turns false, the **branch** and everything in it leave the page.

## A hidden branch is gone, not covered

A *branch* is the part inside `@if { }`. It isn't hidden with CSS; it's removed, and built fresh next time.

- Closing removes the elements and what you typed in them.
- Opening builds new, empty ones.
- A value declared above the `@if` outlives it.

```tsrx title="note-panel.tsrx"
import { computed, state } from '@markless/core';

export default function NotePanel() @{
	let open = state(false);
	let note = state('');
	const long = computed(() => note.length > 20);

	<section>
		<button onClick={() => (open = !open)}>
			Show or hide the note
		</button>
		@if (open) {
			<label>
				Note
				<input
					value={note}
					onInput={(event) =>
						(note = event.currentTarget.value)
					}
				/>
			</label>
		}
		@if (long) {
			<p>That is a long note.</p>
		} @else {
			<p>Short and sweet.</p>
		}
	</section>
}
```

## `@else` and `@switch` pick one of several

- `@else` covers the other side. A plain `else` stops the build with `MARKLESS_BRANCH_ELSE_SPELLING`.
- `@switch (status) { @case 'ready': { … } @default: { … } }` picks one case.

Not yet:

- An `@if` or `@switch` can't sit inside another `@if`, and `@else if` doesn't work: `MARKLESS_BRANCH_ARM_UPDATE_UNSUPPORTED`. Put branches side by side, or use `@switch`.
- `state()` inside an `@if` stops the build with `MARKLESS_STATE_CREATION_SITE_UNSTABLE`.
