# Conditionals

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="@if shows its elements while a condition is true, and removes them when it isn't." terms="elements" />

```tsrx title="note-field.tsrx"
import { state } from '@markless/core';

export default function NoteField() @{
	let open = state(true);

	@if (open) {
		<textarea placeholder="write here" />
	}
}
```

**`@if (open)`** builds the `<textarea>` while `open` is true. When `open` turns false, everything inside the **`@if`** leaves the page.

## A closed `@if` is gone, not covered

A *condition* is the true-or-false value in `@if ( )`. When it turns false, the part inside isn't hidden with CSS; it's removed, and built fresh next time.

- Closing removes the elements and what you typed in them.
- Opening builds new, empty ones.
- A value declared above the `@if` outlives it.

```tsrx title="note-panel.tsrx"
import { computed, state } from '@markless/core';

export default function NotePanel() @{
	let open = state(false);
	let note = state('');
	const long = computed(() => note.length > 20);

	<section>
		<button onClick={() => (open = !open)}>
			Show or hide the note
		</button>
		@if (open) {
			<label>
				Note
				<input
					value={note}
					onInput={(event) =>
						(note = event.currentTarget.value)
					}
				/>
			</label>
		}
		@if (long) {
			<p>That is a long note.</p>
		} @else {
			<p>Short and sweet.</p>
		}
	</section>
}
```

## `@else` and `@switch` pick one of several

`@else` shows what to put there when the condition is false, and `@switch` picks one `@case` from several. Put `@if` blocks side by side; one can't sit inside another yet.
