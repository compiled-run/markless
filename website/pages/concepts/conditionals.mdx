# A hidden branch is not hidden, it is gone

<PageMeta time="3 min" assumes="state, computed, events" />

<ThemeToggle />

<Subtitle text="@if puts real elements on the page and takes them off again. A value outlives the branch only if you declare it above the branch." terms="elements" />

You type half a note into a panel, close it by accident, and open it again. The note is gone.

```tsrx title="note-field.tsrx"
import { state } from '@markless/core';

export default function NoteField() @{
	let open = state(true);
	let note = state('');

	<section>
		<button onClick={() => (open = !open)}>Note</button>
		@if (open) {
			<input
				value={note}
				onInput={(event) => (note = event.currentTarget.value)}
			/>
		}
	</section>
}
```

The field lives inside the `@if`. The note lives above it, in the component body, so it survives.

## Close the field, open it again

Type in the field, press **Note** to close it, then press **Note** again.

<MugSpot mood="sad" from="left" />

<PanelDemo />

- Closing removes the field from the page. It isn't covered up.
- Opening builds a new field, and it shows `note` again.
- `note` was made once, above the `@if`, so it kept every letter.

## Where you declare a value decides how long it lives

- The component body lasts as long as the component.
- A branch lasts as long as its test is true.
- Put `let note = state('')` inside the `@if`, and the build stops with
  `MARKLESS_STATE_CREATION_SITE_UNSTABLE`: a note made there would leave with the branch.

<Code steps={[{ label: 'Press Show or hide the note, and type a note longer than 20 letters. The line under it changes.', shows: 'That is a long note.' }, { label: 'Change `20` to `5`, and type six letters.', source: 'note.length > 5' }]}>
```tsrx title="note-panel.tsrx"
import { computed, state } from '@markless/core';

export default function NotePanel() @{
	let open = state(false);
	let note = state('');
	const long = computed(() => note.length > 20);

	<section>
		<button onClick={() => (open = !open)}>
			Show or hide the note
		</button>
		@if (open) {
			<label>
				Note
				<input
					value={note}
					onInput={(event) =>
						(note = event.currentTarget.value)
					}
				/>
			</label>
		}
		@if (long) {
			<p>That is a long note.</p>
		} @else {
			<p>Short and sweet.</p>
		}
	</section>
}
```

## `@else` and `@switch`

`@else` covers the other side of the same test. For three or more cases, `@switch` shows the one
`@case` that matches, and `@default` catches the rest:

```tsrx title="order-status.tsrx"
import { state } from '@markless/core';

export default function OrderStatus() @{
	let status = state('brewing');

	<section>
		<button onClick={() => (status = 'ready')}>Mark ready</button>
		@switch (status) {
			@case 'brewing': {
				<p>Brewing your coffee.</p>
			}
			@case 'ready': {
				<p>Ready for pickup.</p>
			}
			@default: {
				<p>Queued.</p>
			}
		}
	</section>
}
```

Not yet:

- A plain `else` stops the build with `MARKLESS_BRANCH_ELSE_SPELLING`. Write `@else`.
- An `@if` or `@switch` can't sit inside another `@if`, and `@else if` chains don't work. Both
  stop the build with `MARKLESS_BRANCH_ARM_UPDATE_UNSUPPORTED`. Put the branches side by side, or
  use `@switch`.
