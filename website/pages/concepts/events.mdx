# Events hand you the browser's own event

<PageMeta time="3 min" assumes="state" />

<ThemeToggle />

<Subtitle text="An event prop is on plus the event name, and your handler gets the browser's own event." terms="events" />

```tsrx
<input onInput={(event) => (name = event.currentTarget.value)} />
```

That is `addEventListener('input', ...)` written on the element. `event.key`, `event.target` and
`event.preventDefault()` are the real ones, so the DOM docs you already know still apply.

## Type, press Enter, press Escape

Type a name, press Enter, then press Escape. The notes say what each handler got from the browser.

<LabelDemo />

- Every key fires `input`, and the preview follows `name`.
- Enter submits the form. `event.preventDefault()` keeps the page from reloading.
- Your component ran once, to set up the page. A handler's code runs only when its event fires.

## Write your own

<Code steps={[{ label: 'Under the preview, add `<p>{name.length} letters</p>` and type a name.', source: '{name.length}' }, { label: 'Change `onInput` to `onChange` and type again. The preview now waits until you leave the field.', source: 'onChange=' }]}>
```tsrx title="mug-label.tsrx"
import { state } from '@markless/core';

export default function MugLabel() @{
	let name = state('');
	let printed = state('nothing yet');

	<form
		onSubmit={(event) => {
			event.preventDefault();
			printed = name;
		}}
	>
		<label>
			Name for the mug
			<input
				value={name}
				onInput={(event) =>
					(name = event.currentTarget.value)
				}
				onKeyDown={(event) => {
					if (event.key === 'Escape') name = '';
				}}
			/>
		</label>
		<p>Preview: {name}</p>
		<p>Printed: {printed}</p>
		<button type="submit">Print it</button>
	</form>
}
```
</Code>

## Naming the prop

- Write `on` and the event name: `onClick`, `onInput`, `onKeyDown`.
- The case after `on` doesn't matter, so `onKeydown` works too.
- Pass an array to run two handlers in order: `onClick={[save, countSave]}`.

## Run code when the page is idle or in view

Some code belongs on the page but no click asks for it, like an analytics tag. Put `onIdle` on the
element it belongs to:

```tsrx title="footer.tsrx"
export default function Footer() @{
	<footer
		onIdle={async () => {
			const analytics = await import('./analytics.ts');
			analytics.start();
		}}
	>
		Made by Beanshop
	</footer>
}
```

- `onIdle` runs once per element, after the page loads and the browser is idle.
- `onVisible` runs once, the first time the element scrolls into view.
- An element inside an `@if` or `@for` runs it after it appears. One that's gone by then never
  does.
- A handler's code downloads only when it runs, and so does the `import()` inside it.

## What a handler can read

- State, props, imports, and `const` values built from those.
- A function you declared in the component body, with arguments: `onClick={() => add(2)}`.
- Not a plain `let` from the component body: `MARKLESS_HANDLER_READS_RENDER_LOCAL`.
- A body `const` is built again for each event, so changing it, as in `list.push(3)`, stops the
  build with `MARKLESS_HANDLER_WRITES_RENDER_LOCAL`. Keep changing data in `state()`.
- `event.preventDefault()` inside an `if` runs the moment the event fires, so the test may read
  only state, props, constants or an event field compared with a fixed value, like
  `event.key === 'Enter'`. Anything else stops the build with `MARKLESS_SYNC_POLICY_UNEXTRACTABLE`.
