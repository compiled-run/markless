# Events

<PageMeta time="2 min" assumes="state" />

<Subtitle text="An event prop runs your handler when the browser fires one of its events, and hands it the real event object." terms="events" />

```tsrx title="name-field.tsrx"
import { state } from '@markless/core';

export default function NameField() @{
	let name = state('');

	<input onInput={(event) => (name = event.currentTarget.value)} />
}
```

**`onInput`** is `on` plus the browser's `input` event. The **`event`** your handler gets is the real one, so `event.currentTarget.value` is what was typed.

## A handler runs when its event fires

An *event* is something a person does: a key press, a click, a tap. Your handler runs once for each one, and never before.

- The browser makes the event, with every field it always has.
- Your handler gets that same object: `event.key`, `event.target`, `event.preventDefault()`.
- No event, no run.

Press the key, or click it and type on your own keyboard.

```tsrx title="mug-label.tsrx"
import { state } from '@markless/core';

export default function MugLabel() @{
	let name = state('');
	let printed = state('nothing yet');

	<form
		onSubmit={(event) => {
			event.preventDefault();
			printed = name;
		}}
	>
		<label>
			Name for the mug
			<input
				value={name}
				onInput={(event) =>
					(name = event.currentTarget.value)
				}
				onKeyDown={(event) => {
					if (event.key === 'Escape') name = '';
				}}
			/>
		</label>
		<p>Preview: {name}</p>
		<p>Printed: {printed}</p>
		<button type="submit">Print it</button>
	</form>
}
```

## Name the prop after the event

- `on` plus the event name: `onClick`, `onInput`, `onKeyDown`. The case after `on` doesn't matter.
- Pass an array to run two handlers in order: `onClick={[save, countSave]}`.
- `onIdle` runs once when the page is idle, and `onVisible` once when the element scrolls into view.

Not yet:

- A handler can't read a plain `let` from the component body: `MARKLESS_HANDLER_READS_RENDER_LOCAL`.
- Changing a body `const`, as in `list.push(3)`, stops the build with `MARKLESS_HANDLER_WRITES_RENDER_LOCAL`. Keep changing data in `state()`.
- `event.preventDefault()` inside an `if` needs a test on state, props, constants or an event field, like `event.key === 'Enter'`: `MARKLESS_SYNC_POLICY_UNEXTRACTABLE`.
