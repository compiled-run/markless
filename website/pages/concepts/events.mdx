# Events hand you the browser's own event

<PageMeta time="2 min" assumes="state" />

<Subtitle text="An event prop is on plus the event name, and your handler gets the browser's own event." />

```tsrx
<input onInput={(event) => (name = event.currentTarget.value)} />
```

That is `addEventListener('input', …)` written on the element. `event.key` and `event.preventDefault()` are the real ones.

## Strike a key

The keys are the browser, and the roller lettered `onInput` is your handler. Press the drawing to strike a key.

<TypingAnatomy />

Each strike is one event that carries its key. The handler runs only then, and only the field and the preview change.

## Write your own

<Code steps={[{ label: 'Under the preview, add `<p>{name.length} letters</p>` and type a name.', source: '{name.length}' }, { label: 'Change `onInput` to `onChange` and type again. The preview now waits until you leave the field.', source: 'onChange=' }]}>
```tsrx title="mug-label.tsrx"
import { state } from '@markless/core';

export default function MugLabel() @{
	let name = state('');
	let printed = state('nothing yet');

	<form
		onSubmit={(event) => {
			event.preventDefault();
			printed = name;
		}}
	>
		<label>
			Name for the mug
			<input
				value={name}
				onInput={(event) =>
					(name = event.currentTarget.value)
				}
				onKeyDown={(event) => {
					if (event.key === 'Escape') name = '';
				}}
			/>
		</label>
		<p>Preview: {name}</p>
		<p>Printed: {printed}</p>
		<button type="submit">Print it</button>
	</form>
}
```
</Code>

## Naming the prop

- `on` plus the event name: `onClick`, `onInput`, `onKeyDown`. The case after `on` doesn't matter.
- Pass an array to run two handlers in order: `onClick={[save, countSave]}`.
- `onIdle` runs once when the page is idle, and `onVisible` once when the element scrolls into view.

Not yet:

- A handler can't read a plain `let` from the component body: `MARKLESS_HANDLER_READS_RENDER_LOCAL`.
- Changing a body `const`, as in `list.push(3)`, stops the build with `MARKLESS_HANDLER_WRITES_RENDER_LOCAL`. Keep changing data in `state()`.
- `event.preventDefault()` inside an `if` needs a test on state, props, constants or an event field, like `event.key === 'Enter'`: `MARKLESS_SYNC_POLICY_UNEXTRACTABLE`.
