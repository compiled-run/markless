# A key tells the page which row is which

<PageMeta level="Start here" time="5 min" assumes="state, events, conditionals" sprite="dashes" />

<ThemeToggle />

You tick a row in a list. You sort the list. The tick is now on somebody else's row.

Nothing crashed. The page saw three slots and filled them again from the top. It had no idea the rows
were the same rows in a new order.

**A key answers "which row is this?" Once a row has a key, everything on that row moves with it.**

## Tick a row, then sort

Tick **Pears**. Press **Sort A to Z**. Then press **Remove ticked** until the list is empty.

Pears moves to the bottom, and its tick goes with it. The sort did not build new rows. It moved the
three rows that were already on the page into a new order. When the last row goes, the `@empty`
block shows instead.

```tsrx
import { state } from '@markless/core';

export default function ShoppingList() @{
	let items = state([
		{ id: 'pears', name: 'Pears', done: false },
		{ id: 'coffee', name: 'Coffee', done: false },
		{ id: 'milk', name: 'Milk', done: false },
	]);

	<section>
		<ul>
			@for (const item of items; key item.id) {
				<li>
					<label>
						<input type="checkbox" checked={item.done} onChange={() => (item.done = !item.done)} />
						{item.name}
					</label>
				</li>
			} @empty {
				<li>Nothing left to buy.</li>
			}
		</ul>
		<button onClick={() => (items = [...items].sort((a, b) => a.name.localeCompare(b.name)))}>
			Sort A to Z
		</button>
		<button onClick={() => (items = items.filter((item) => !item.done))}>Remove ticked</button>
	</section>
}
```

`key item.id` in the loop header is the whole identity story. Each row's checkbox handler changes
`item.done` on its own item, wherever that row sits.

## Choosing a key

Use the value that names the item in your data: an id, a slug, an order number. It must be unique
in the list, and the same item must carry the same key every time.

Avoid two things. The position names the slot, not the item, so it brings the original bug back. And
a value the reader can edit turns a renamed row into a new row.

To get the position for display, add `index i` to the header. Keep the key on the data:

```tsrx
import { state } from '@markless/core';

export default function Steps() @{
	let steps = state([
		{ id: 'grind', text: 'Grind the beans' },
		{ id: 'pour', text: 'Pour the water' },
	]);

	<ol>
		@for (const step of steps; index i; key step.id) {
			<li>
				{i + 1}: {step.text}
			</li>
		}
	</ol>
}
```
