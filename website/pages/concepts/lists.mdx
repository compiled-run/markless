# Lists

<PageMeta time="5 min" assumes="state, events, computed" />

<Subtitle text="@for draws one row per item, and a key tells the page which row is which." />

```tsrx title="shelf.tsrx"
import { state } from '@markless/core';

export default function Shelf() @{
	let books = state([
		{ id: 'dune', title: 'Dune' },
		{ id: 'emma', title: 'Emma' },
	]);

	<ul>
		@for (const book of books; key book.id) {
			<li>{book.title}</li>
		}
	</ul>
}
```

**`@for`** draws one `<li>` per book. **`key book.id`** names each row by its data, so the page can tell the rows apart.

## Every row needs a key

A *key* is a value that names one item for good, like an id. Every `@for` needs one, even over a list that never changes.

## Add and remove rows

Change the array the way you change any array: `push`, `splice` or `filter`. The page adds or removes just those rows. **`@empty`** shows instead when the list has no rows. Keys must be unique: two books with the id `ulysses` would be one row too many.

<Code steps={[{ label: 'Remove Emma, then Dune. The `@empty` line takes over.', shows: 'The shelf is empty.' }, { label: "Add a button that runs `books.splice(0, 1)` to take the first book off.", source: 'books.splice(0, 1)' }]}>
```tsrx title="shelf-edit.tsrx"
import { state } from '@markless/core';

export default function ShelfEdit() @{
	let books = state([
		{ id: 'dune', title: 'Dune' },
		{ id: 'emma', title: 'Emma' },
	]);
	function remove(id: string) {
		books = books.filter((b) => b.id !== id);
	}

	<section>
		<ul>
			@for (const book of books; key book.id) {
				<li>
					{book.title}
					<button onClick={() => remove(book.id)}>
						Remove
					</button>
				</li>
			} @empty {
				<li>The shelf is empty.</li>
			}
		</ul>
		<button
			onClick={() =>
				books.push({
					id: 'ulysses',
					title: 'Ulysses',
				})
			}
		>
			Add Ulysses
		</button>
	</section>
}
```
</Code>

## A row's own state moves with its key

When a row needs state of its own, like a tick, make the row a component in its own file, here `book-row.tsrx`. Each row gets its own `state()`, and the key keeps it with its book when the list moves.

- Reverse or sort the list, and each row moves with its item.
- What the row holds rides along.
- No row is built again.

Press **Reverse**, or drag a card onto another place.

```tsrx title="book-row.tsrx"
import { state } from '@markless/core';

export function BookRow({
	title,
}: {
	title: string;
}) @{
	let reading = state(false);

	<li>
		<label>
			<input
				type="checkbox"
				checked={reading}
				onChange={() => (reading = !reading)}
			/>
			{title}
			{reading ? ', reading' : ''}
		</label>
	</li>
}
```
</Code>

## Change one row in place

To change one row, write to its item: `book.read = !book.read`. Only that row updates, and so does anything worked out from the list.

<Code steps={[{ label: 'Tick Dune.', shows: 'Read: 2' }, { label: 'Add a button under the list that marks every book read: `books.forEach((b) => (b.read = true))`.', source: 'b.read = true' }]}>
```tsrx title="read-flags.tsrx"
import { computed, state } from '@markless/core';

export default function ReadFlags() @{
	let books = state([
		{ id: 'dune', title: 'Dune', read: false },
		{ id: 'emma', title: 'Emma', read: true },
	]);
	const done = computed(
		() => books.filter((b) => b.read).length,
	);

	<section>
		<ul>
			@for (const book of books; key book.id) {
				<li>
					<label>
						<input
							type="checkbox"
							checked={book.read}
							onChange={() =>
								(book.read = !book.read)
							}
						/>
						{book.title}
					</label>
				</li>
			}
		</ul>
		<p>Read: {done}</p>
	</section>
}
```
</Code>

A row component can't write to the object it was given. Pass it a function to call instead, as [Components](/build/components) shows.

## Filter and sort with a computed

The rows you show are worked out from the full list, so put that in a `computed`. Type on the drawer's label: the cards that don't match sink, and the rest close up in their order.

<DrawerAnatomy />

<Code steps={[{ label: 'Type em.', shows: 'Emma' }, { label: 'Sort them: add `.toSorted((a, b) => a.title.localeCompare(b.title))` after the filter.', source: '.toSorted(' }, { label: 'Type zz. The `@empty` line shows.', shows: 'No match.' }]}>
```tsrx title="search-shelf.tsrx"
import { computed, state } from '@markless/core';

export default function SearchShelf() @{
	let query = state('');
	let books = state([
		{ id: 'dune', title: 'Dune' },
		{ id: 'emma', title: 'Emma' },
		{ id: 'ulysses', title: 'Ulysses' },
	]);
	const shown = computed(() =>
		books.filter((book) =>
			book.title
				.toLowerCase()
				.includes(query.toLowerCase()),
		),
	);

	<section>
		<input
			value={query}
			onInput={(event) =>
				(query = event.currentTarget.value)
			}
		/>
		<ul>
			@for (const book of shown; key book.id) {
				<li>{book.title}</li>
			} @empty {
				<li>No match.</li>
			}
		</ul>
	</section>
}
```
</Code>

## Loop over a Set or a Map

`@for` reads a `Set` or a `Map` directly. Pull a Map's key and value apart with `[t, n]`. For a plain object, loop over `computed(() => Object.entries(prices))`.

<Code steps={[{ label: 'Press Add poetry, then Add Kim.', shows: 'Kim: 3' }]}>
```tsrx title="genres.tsrx"
import { state } from '@markless/core';

export default function Genres() @{
	let genres = state(
		new Set(['novel', 'sci-fi']),
	);
	let copies = state(
		new Map([
			['Dune', 2],
			['Emma', 1],
		]),
	);

	<section>
		<ul>
			@for (const genre of genres; key genre) {
				<li>{genre}</li>
			}
		</ul>
		<ul>
			@for (const [t, n] of copies; key t) {
				<li>{t}: {n}</li>
			}
		</ul>
		<button onClick={() => genres.add('poetry')}>
			Add poetry
		</button>
		<button onClick={() => copies.set('Kim', 3)}>
			Add Kim
		</button>
	</section>
}
```
</Code>

## Number the rows with index

`index i` gives each row its place, for display. The key stays on the data:

```tsrx
@for (const book of books; index i; key book.id) {
	<li>{i + 1}. {book.title}</li>
}
```

## Repeat a fixed number of times

Loop over a short array of numbers, keyed by the number:

```tsrx
@for (const n of [1, 2, 3, 4, 5]; key n) {
	<span>{n <= stars ? '★' : '☆'}</span>
}
```
