# A key tells the page which row is which

<PageMeta time="2 min" assumes="state, events, conditionals" />

<Subtitle text="A key answers which row is this. Once a row has one, everything on that row moves with it." />

You tick a row and sort the list. The tick is now on somebody else's row: the page filled three
slots again from the top, with no idea they were the same rows in a new order.

```tsrx title="guests.tsrx"
import { state } from '@markless/core';

export default function Guests() @{
	let guests = state([{ id: 'ada', name: 'Ada' }]);

	<ul>
		@for (const guest of guests; key guest.id) {
			<li>{guest.name}</li>
		}
	</ul>
}
```

`@for` draws one row per item. `key guest.id` names each row by its data, not its place.

## Tick a row, then sort

Tick **Pears**, then press **Sort A to Z** and **Reverse**.

- Each ring and each tick stays with its row.
- A reorder moves the rows already on the page. It builds none.

## Change the list

<Code steps={[{ label: "Add `{ id: 'beans', name: 'Beans', done: false }` to the starting list.", shows: 'Beans' }, { label: 'Tick every row and press Remove ticked. The `@empty` line takes over.', shows: 'Nothing left to buy.' }]}>
```tsrx title="shopping-list.tsrx"
import { state } from '@markless/core';

export default function ShoppingList() @{
	let items = state([
		{ id: 'pears', name: 'Pears', done: false },
		{ id: 'coffee', name: 'Coffee', done: false },
		{ id: 'milk', name: 'Milk', done: false },
	]);

	<section>
		<ul>
			@for (const item of items; key item.id) {
				<li>
					<label>
						<input
							type="checkbox"
							checked={item.done}
							onChange={() =>
								(item.done = !item.done)
							}
						/>
						{item.name}
					</label>
				</li>
			} @empty {
				<li>Nothing left to buy.</li>
			}
		</ul>
		<button
			onClick={() =>
				(items = [...items].sort((a, b) =>
					a.name.localeCompare(b.name),
				))
			}
		>
			Sort A to Z
		</button>
		<button
			onClick={() =>
				(items = items.filter(
					(item) => !item.done,
				))
			}
		>
			Remove ticked
		</button>
	</section>
}
```
</Code>

`@empty` shows when the list has no rows.

## Choosing a key

- Use what names the item in your data: an id, a slug, an order number.
- It must be unique in the list, and the same item must keep the same key.
- Not the position: that names the slot, and brings the ticked-row bug back.
- Not a value the reader edits: a renamed row would become a new row.

Need the position for display? Add `index i` and keep the key on the data:

```tsrx
@for (const step of steps; index i; key step.id) {
	<li>{i + 1}: {step.text}</li>
}
```

Not yet:

- Every `@for` needs a key. Without one the build stops with `MARKLESS_REPEAT_KEY_REQUIRED`.
- `key i` builds with a `MARKLESS_REPEAT_KEY_IS_INDEX` warning, and each row then follows its slot.
