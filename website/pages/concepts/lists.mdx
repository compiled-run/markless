# Lists

<Subtitle text="@for draws one row per item, and a key tells the page which row is which." />

```tsrx title="guests.tsrx"
import { state } from '@markless/core';

export default function Guests() @{
	let guests = state([{ id: 'ada', name: 'Ada' }]);

	<ul>
		@for (const guest of guests; key guest.id) {
			<li>{guest.name}</li>
		}
	</ul>
}
```

**`@for`** draws one `<li>` per guest. **`key guest.id`** names each row by its data, so the page can tell the rows apart.

## A key makes each row follow its item

A *key* is a value that names one item for good, like an id. With it, a row keeps its place in your data, not its place on the page.

- Reorder the list, and each row moves with its item.
- What a row holds, like a tick, rides along.
- No row is built again.

Press **Reverse**, or drag a card onto another slot.

```tsrx title="shopping-list.tsrx"
import { state } from '@markless/core';

export default function ShoppingList() @{
	let items = state([
		{ id: 'pears', name: 'Pears', done: false },
		{ id: 'coffee', name: 'Coffee', done: false },
		{ id: 'milk', name: 'Milk', done: false },
	]);

	<section>
		<ul>
			@for (const item of items; key item.id) {
				<li>
					<label>
						<input
							type="checkbox"
							checked={item.done}
							onChange={() =>
								(item.done = !item.done)
							}
						/>
						{item.name}
					</label>
				</li>
			} @empty {
				<li>Nothing left to buy.</li>
			}
		</ul>
		<button
			onClick={() =>
				(items = [...items].sort((a, b) =>
					a.name.localeCompare(b.name),
				))
			}
		>
			Sort A to Z
		</button>
		<button
			onClick={() =>
				(items = items.filter(
					(item) => !item.done,
				))
			}
		>
			Remove ticked
		</button>
	</section>
}
```
</Code>

## Pick a key that names the item

- Use what names the item in your data: an id, a slug, an order number.
- It must be unique in the list, and the same item must keep the same key.
- Not the position: a tick would then stay with the slot, not the item.
- Not a value the reader edits: a renamed row would become a new row.

Need the position for display? Add `index i` and keep the key on the data:

```tsrx
@for (const step of steps; index i; key step.id) {
	<li>{i + 1}: {step.text}</li>
}
```

Not yet:

- Every `@for` needs a key. Without one the build stops with `MARKLESS_REPEAT_KEY_REQUIRED`.
- `key i` builds with a `MARKLESS_REPEAT_KEY_IS_INDEX` warning, and each row then follows its slot.
