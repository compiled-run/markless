# State

<PageMeta time="6 min" assumes="reading-tsrx" />

<Subtitle text="State is one of your values that the page watches: change it, and every spot that shows it updates." terms="values" />

```tsrx title="profile.tsrx"
import { state } from '@markless/core';

export default function Profile() @{
	let name = state('Jack');

	<section>
		<h2>Hello, {name}</h2>
		<button onClick={() => (name = 'Ada')}>
			Switch user
		</button>
	</section>
}
```

**`state('Jack')`** makes `name` a value the page watches. It's still a plain **`let`**: you read it as `name` and change it with `=`.

## A plain variable isn't watched

A *plain variable* is one without `state()`. Here is `let cart = 0` as a jar beside a shop page. Press **Add to cart**.

<StateAnatomy wired={false} />

The jar fills up, but the page still says 0. Nothing tells the page that `cart` changed.

## Follow the wire

It is still a `let`, read as `cart` and changed with `cart++`. Before the page runs, Markless wires
`cart` to every spot that shows it. Press **Add to cart** again.

<StateAnatomy />

- Every spot that shows the value changes together.
- Only the handler you pressed runs.
- The component function never runs again. It ran once, to set up the page.

<Collapsible sprite="star-badge" summary="How do existing tools handle this?">

Most tools make you change a value in a special way: through a setter, then they run your whole
component again and compare, or through a `.value` container they can watch.

Markless keeps `name` a plain `let`. You write `name = 'Ada'`, your component never runs again,
and the change goes straight to the spots that show it.

</Collapsible>

## Numbers, text and true/false change with any assignment

`seconds += 10`, `count++`, `count--` and `playing = !playing` all count. So does any string method on the right of the `=`, like `name = name.trim()`.

<Code steps={[{ label: 'Press Skip 10s twice.', shows: '20s, paused' }, { label: 'Add a Back 10s button that runs `seconds -= 10`.', source: 'seconds -= 10' }, { label: 'Show `{playing}` on its own line, and press Play or pause.', source: '{playing}</' }]}>
```tsrx title="player.tsrx"
import { state } from '@markless/core';

export default function Player() @{
	let seconds = state(0);
	let playing = state(false);

	<section>
		<p>
			{seconds}s, {playing ? 'playing' : 'paused'}
		</p>
		<button onClick={() => (playing = !playing)}>
			Play or pause
		</button>
		<button onClick={() => (seconds += 10)}>
			Skip 10s
		</button>
	</section>
}
```
</Code>

## An object changes field by field

Put an object in `state()` and change one field with a plain assignment. `person.age++` updates the spots that show `age`. The spots that show `name` stay as they are.

<IdCardAnatomy />

<Code steps={[{ label: 'Press Birthday.', shows: 'Age 25' }, { label: "Add a Rename button that runs `person.name = 'Ada'`.", source: "person.name = 'Ada'" }, { label: 'Add `<p>{person.name} is {person.age}</p>`, and press Birthday again.', source: '<p>{person.name} is {person.age}</p>' }]}>
```tsrx title="person.tsrx"
import { state } from '@markless/core';

export default function Person() @{
	let person = state({ name: 'Jack', age: 24 });

	<section>
		<h2>{person.name}</h2>
		<p>Age {person.age}</p>
		<button onClick={() => person.age++}>
			Birthday
		</button>
	</section>
}
```
</Code>

A field inside a field works the same way, at any depth:

```tsrx
let person = state({ name: 'Jack', address: { city: 'Austin' } });

<button onClick={() => (person.address.city = 'Denver')}>Move</button>
```

## Replace the whole object, or change one field

All three buttons below update the page. Pick the one that says what you mean: a new person, a copy with one change, or new values for some fields.

<Code steps={[{ label: 'Press Copy older.', shows: 'Jack, 25' }, { label: 'Press Swap, then Assign.', shows: 'Bo, 36' }]}>
```tsrx title="swap.tsrx"
import { state } from '@markless/core';

export default function Swap() @{
	let person = state({ name: 'Jack', age: 24 });

	<section>
		<p>{person.name}, {person.age}</p>
		<button
			onClick={() =>
				(person = { name: 'Ada', age: 36 })
			}
		>
			Swap
		</button>
		<button
			onClick={() =>
				(person = {
					...person,
					age: person.age + 1,
				})
			}
		>
			Copy older
		</button>
		<button
			onClick={() =>
				Object.assign(person, { name: 'Bo' })
			}
		>
			Assign
		</button>
	</section>
}
```
</Code>

## A field you add later shows up

A field can be missing at first. The page shows it as soon as you write it.

```tsrx
let person = state<{ name: string; nickname?: string }>({ name: 'Jack' });

<p>{person.nickname ?? 'no nickname'}</p>
<button onClick={() => (person.nickname = 'J')}>Nickname</button>
```

## Fields you pull out stay live

`const { name, age } = person` doesn't copy the values. `age` keeps reading the state, so the page shows the new age after a birthday.

```tsrx
let person = state({ name: 'Jack', age: 24 });
const { name, age } = person;

<p>{name} is {age}</p>
<button onClick={() => person.age++}>Birthday</button>
```

## An array changes with the methods you know

Change an array in place, or replace it with a new one. Both update the page.

- **Change it in place:** `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`, `copyWithin`, `songs[0] = 'Milestones'`, `songs.length = 1`.
- **Replace it:** `songs = songs.filter(...)`, `songs = [...songs, 'Milestones']`, `songs = songs.toSorted()`.

<JCardAnatomy />

<Code steps={[{ label: 'Press Add, then Reverse.', shows: 'Freddie, Blue in Green, So What' }, { label: 'Add a Sort button that runs `songs.sort()`.', source: 'songs.sort()' }, { label: 'Add a Clear button that runs `songs = []`.', source: 'songs = []' }]}>
```tsrx title="playlist.tsrx"
import { state } from '@markless/core';

export default function Playlist() @{
	let songs = state(['So What', 'Blue in Green']);

	<section>
		<p>{songs.join(', ')}</p>
		<p>{songs.length} songs</p>
		<button onClick={() => songs.push('Freddie')}>
			Add
		</button>
		<button onClick={() => songs.pop()}>
			Remove last
		</button>
		<button onClick={() => songs.reverse()}>
			Reverse
		</button>
	</section>
}
```
</Code>

## Objects inside an array change like any object

Find the object and change its field: `chores[0].done = true`, a `for` loop, or `forEach` all update the page.

<Code steps={[{ label: 'Press Do everything.', shows: 'Water plants: done' }, { label: 'Make the button flip only the first chore: `chores[0].done = !chores[0].done`.', source: 'chores[0].done = !chores[0].done' }]}>
```tsrx title="chores.tsrx"
import { state } from '@markless/core';

export default function Chores() @{
	let chores = state([
		{ id: 1, text: 'Water plants', done: false },
		{ id: 2, text: 'Take out bins', done: false },
	]);

	<section>
		<p>
			{chores[0].text}:
			{chores[0].done ? ' done' : ' to do'}
		</p>
		<button
			onClick={() =>
				chores.forEach((c) => (c.done = true))
			}
		>
			Do everything
		</button>
	</section>
}
```
</Code>

To show every chore, not only the first, see [Lists](/concepts/lists).

## A Map updates on set and delete

Put a `Map` in `state()`. `votes.get(...)`, `votes.has(...)` and `votes.size` update after `votes.set(...)`, `votes.delete(...)` and `votes.clear()`.

<Code steps={[{ label: 'Press Add sushi.', shows: 'Dishes: 3' }, { label: "Add a Remove tacos button that runs `votes.delete('tacos')`.", source: "votes.delete('tacos')" }, { label: "Show `{votes.has('sushi') ? 'yes' : 'no'}`, and press Add sushi.", source: "votes.has('sushi')" }]}>
```tsrx title="poll.tsrx"
import { state } from '@markless/core';

export default function Poll() @{
	let votes = state(
		new Map([
			['pizza', 2],
			['tacos', 1],
		]),
	);
	function vote(dish: string) {
		votes.set(dish, (votes.get(dish) ?? 0) + 1);
	}

	<section>
		<p>Pizza: {votes.get('pizza')}</p>
		<p>Dishes: {votes.size}</p>
		<button onClick={() => vote('pizza')}>
			Vote pizza
		</button>
		<button onClick={() => votes.set('sushi', 1)}>
			Add sushi
		</button>
	</section>
}
```
</Code>

## A Set updates on add and delete

A `Set` keeps one copy of each value, as it always does in JavaScript. `tags.has(...)` and `tags.size` update after `tags.add(...)` and `tags.delete(...)`.

<Code steps={[{ label: 'Press Add bebop twice. The count stays at 2.', shows: 'Tags: 2' }, { label: 'Press Remove jazz.', shows: 'Jazz: no' }]}>
```tsrx title="tags.tsrx"
import { state } from '@markless/core';

export default function Tags() @{
	let tags = state(new Set(['jazz']));

	<section>
		<p>Tags: {tags.size}</p>
		<p>Jazz: {tags.has('jazz') ? 'yes' : 'no'}</p>
		<button onClick={() => tags.add('bebop')}>
			Add bebop
		</button>
		<button onClick={() => tags.delete('jazz')}>
			Remove jazz
		</button>
	</section>
}
```
</Code>

## A Date updates through its own set methods

Call a `set` method on the date, or assign a new date. Both update the page.

```tsrx
let birthday = state(new Date('2026-11-05T00:00:00Z'));

<p>{birthday.toDateString()}</p>
<button onClick={() => birthday.setUTCDate(birthday.getUTCDate() + 1)}>Next day</button>
```

## A write can come later

A handler can change state after an `await` or inside a timer. The page shows each change when it happens.

<Code steps={[{ label: 'Press the button and watch it say saving, then saved.', shows: 'saved' }, { label: 'Change 800 to 2000. Saving now stays on screen for two seconds.', source: 'wait(2000)' }]}>
```tsrx title="save.tsrx"
import { state } from '@markless/core';

function wait(ms: number) {
	return new Promise((done) =>
		setTimeout(done, ms),
	);
}

export default function Save() @{
	let status = state('idle');

	<button
		onClick={async () => {
			status = 'saving';
			await wait(800);
			status = 'saved';
		}}
	>
		{status}
	</button>
}
```
</Code>

## A function can change state you pass it

Pass `person` to a function, and the function's change reaches the page:

```tsrx
function birthday(p: { age: number }) {
	p.age++;
}

<button onClick={() => birthday(person)}>Birthday</button>
```

## Give state a type

TypeScript takes the type from the starting value. When the starting value is narrower than what the state will hold, pass the type: `state<T>(initial: T): T`.

```tsrx
type Sort = 'newest' | 'oldest';

let sort = state<Sort>('newest');
let todos = state<Todo[]>([]);
```

## Make state in the component body

Write `state()` next to your other variables in the component body. Not above the component, not inside a handler, and not inside an `@if` or `@for`. It only works in `.tsrx` files. For a value that several components share, use [shared](/build/shared).

<Code steps={[{ label: "Try breaking it: move `let name = state('Jack');` above `export default function`. The build stops, because state up there would be shared by every visitor.", fails: 'MARKLESS_STATE_MODULE_SCOPE' }]}>
```tsrx title="profile.tsrx"
import { state } from '@markless/core';

export default function Profile() @{
	let name = state('Jack');

	<section>
		<h2>Hello, {name}</h2>
		<button onClick={() => (name = 'Ada')}>
			Switch user
		</button>
	</section>
}
```
</Code>

## What the page can't watch

The build stops on each of these, so you find out before the page runs:

- A plain `let` changed in a handler. Wrap it in `state()`.
- A function kept in state. Keep the data in state, and the function outside it.
- A field changed on an object you read out of a Map or a Set. Put a new object back with `votes.set(...)` instead.

Don't keep class instances in state yet. Use plain objects, and plain functions to change them.

[Events](/concepts/events) shows the handlers that make these changes.
