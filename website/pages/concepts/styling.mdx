# Styling

<PageMeta time="2 min" assumes="state" />

<Subtitle text="A style block inside a component styles that file's elements and nothing else." terms="elements" />

```tsrx title="profile-card.tsrx"
export default function ProfileCard() @{
	<article class="card">
		<style>
			.card {
				background: peachpuff;
			}
		</style>
		<p>Ada Lovelace</p>
	</article>
}
```

The **`<style>` block** sits inside the component. Its **`.card`** rule reaches this file's `<article>`, and no other file's.

## The same class name never collides

A *scoped* rule is one that reaches only its own file's elements. Markless adds a class made from the file's path, starting `mk-`, to the file's selectors and elements.

- Two files can both style `.card`.
- Each rule paints only its own file's card.
- A rule in an imported stylesheet, like `global.css`, reaches every card.

Change either file's colour, and hover a card to see its classes.

```tsrx title="paper-card.tsrx"
export default function PaperCard() @{
	<article class="card">
		<style>
			.card {
				padding: 0.6em 0.9em;
				border: 2px solid currentColor;
				background: lightyellow;
				color: black;
			}
		</style>
		<p>Paper card</p>
	</article>
}
```

```tsrx title="chalk-card.tsrx"
import { state } from '@markless/core';

export default function ChalkCard() @{
	let lit = state(false);

	<article class={lit ? 'card lit' : 'card'}>
		<style>
			.card {
				padding: 0.6em 0.9em;
				border: 2px dashed currentColor;
				background: darkslategray;
				color: white;
			}
			.lit {
				background: plum;
				color: black;
			}
		</style>
		<p>Chalk card</p>
		<button onClick={() => (lit = !lit)}>
			Light it up
		</button>
	</article>
}
```

## The extra class belongs to the file

Two components in one `.tsrx` file share one class, so give a component its own file to give it its own styles. For rules that cover the whole site, import an ordinary stylesheet.

<Collapsible sprite="thought-bubble" summary="How do existing tools handle this?">

Scoped styles in single-file components work much the same way. You write the plain class name,
and the build adds one class per file to selectors and elements. In the inspector you see your
own class name next to the added one.
