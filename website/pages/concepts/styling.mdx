# Styling

<Subtitle text="A style block styles the elements beside it and below it, and nothing else." terms="elements" />

```tsrx title="profile-card.tsrx"
export default function ProfileCard() @{
	<>
		<style>
			.card {
				background: peachpuff;
			}
		</style>
		<article class="card">
			<p>Ada Lovelace</p>
		</article>
	</>
}
```

The **`<style>` block** sits beside the `<article>` in a fragment. Its **`.card`** rule reaches that `<article>`, and no other component's.

## The same class name never collides

A *scoped* rule is one that reaches only the elements its block styles. Markless adds an extra class, starting `mk-`, to every selector in the block and to every element the block reaches.

- Two components can both style `.card`.
- Each rule paints only its own component's card.
- A rule in an imported stylesheet, like `global.css`, reaches every card.

Change either file's colour, and hover a card to see its classes.

	<>
		<style>
			.card {
				padding: 0.6em 0.9em;
				border: 2px solid currentColor;
				background: lightyellow;
				color: black;
			}

```tsrx title="chalk-card.tsrx"
import { state } from '@markless/core';

export default function ChalkCard() @{
	let lit = state(false);

	<>
		<style>
			.card {
				padding: 0.6em 0.9em;
				border: 2px dashed currentColor;
				background: darkslategray;
				color: white;
			}
			.lit {
				background: plum;
				color: black;
			}
		</style>
		<article class={lit ? 'card lit' : 'card'}>
			<p>Chalk card</p>
			<button onClick={() => (lit = !lit)}>
				Light it up
			</button>
		</article>
	</>
}
```

## What a block reaches

A `<style>` block sits in a list of children: the children of an element, or of a fragment. It styles the other children in that list and everything inside them.

- It never styles the element that contains it. To style an element, put the block and the element side by side in a fragment, as the cards above do.
- Two blocks in the same list share one extra class.
- A block inside a nested element gets an extra class of its own. Rules from the outer block reach into the nested element; rules from the inner block never reach out.
- A rule never reaches a child component, even one written in the same `.tsrx` file. The child styles itself with its own block.

For rules that cover the whole site, import an ordinary stylesheet.
