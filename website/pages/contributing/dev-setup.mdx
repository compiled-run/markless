# Set up the repo on your machine

<PageMeta time="2 min" assumes="nothing" />

<Subtitle text="One pnpm install sets up every package and turns on the git hooks, so your first commit already runs CI's fast checks." />

```bash
git clone https://github.com/compiled-run/markless.git
cd markless
corepack enable
pnpm install
```

## What you need

- **Node 24.** The repo doesn't pin a Node version, but every CI job that installs Node installs 24.
- **pnpm 10.33.2.** The root `package.json` pins it in `packageManager`, and `corepack enable` picks it up.
- **git**, and the **`gh`** command line if you ever push to `main`. The `pre-push` hook uses it.

## `pnpm install` turns on the hooks

Press the drawing, and watch where `pnpm install` points git:

<InstallFigure />

The root `prepare` script sets `core.hooksPath`, so every commit runs lint and CI's fast jobs first.

Some tests start real browsers. Install the ones CI uses:

```bash
pnpm --dir packages/vitest-browser exec playwright install chromium webkit
```

Or run `pnpm ci:local --install`, which runs each job's setup steps, the browser installs among them, before its checks.

## The scripts you'll use

| Script | What it runs |
| --- | --- |
| `pnpm run typecheck` | The `.tsrx`-aware checker, `packages/typescript-plugin/src/tsc.ts`, on the root `tsconfig.json`. |
| `pnpm ci:local --fast` | CI's fast jobs, with the exact commands from `ci.yml`. |
| `pnpm exec vp test <file>` | One test file. Add `--project node`, `browser` or `ui` to run one test project. |
| `pnpm test:compiler` | `packages/compiler/test/*.test.ts`. |
| `pnpm test:headless` | The `ui` test project: the `@markless/ui` browser tests. |
| `pnpm lint`, `pnpm check`, `pnpm fmt` | `vp lint`, `vp check` and `vp fmt`. `vp` is the Vite+ command line. |
| `pnpm build` | Packs the packages with `vp pack`, plus CommonJS builds of `router` and `typescript-plugin`. |
| `pnpm rules` | Regenerates the agent files from `.ruler/`. |
| `pnpm docs:dev` | This website's dev server. |

`pnpm test` is not CI. It runs a different, longer set of commands, so use `pnpm ci:local` to run what CI runs.

## Type-check the whole repo

Plain `tsc` can't read `.tsrx` files. `pnpm run typecheck` wraps it, so every `tsc` flag still works:

<TypecheckFigure />

A file that doesn't parse fails the run too. `pnpm typecheck:ts7` runs the same check on the TypeScript 7.1 beta, and CI runs both. There, a parse error reports `TSRX771000` instead of `TS91001`, and it skips the type errors until every file parses.

[Your first pull request](/contributing/first-pr) puts these commands to work on a real change.
