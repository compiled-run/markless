# Improve the docs

<PageMeta time="3 min" assumes="nothing" />

<Subtitle text="This site is a Markless app in website/, and every page is one file you can open, change and preview." />

```bash title="terminal"
pnpm install
pnpm docs:dev
```

**`pnpm install`** sets up the repo once, and **`pnpm docs:dev`** serves the site at the address it prints. Edit a page and it updates as you save.

## Any size of help counts

A fixed typo is welcome. So is a clearer sentence, a missing example, or a whole new figure. You don't need to know Markless well; if a page confused you, that's exactly the page to fix.

## Readers come here to see how things work

People already get text answers from AI. They open the docs to *see* the idea move. So every idea gets a picture they can play with, and only a few words around it.

## A page's path is its address

A *page file* is an `.mdx` file in `website/pages/`. Move `state.mdx`, or click it to rename it:

<DocsExplorerFigure />

A new page also needs an entry in `website/nav.ts`.

## Every page has the same shape

Open `pages/start/reading-tsrx.mdx` beside your page and match it:

- a plain title, then a subtitle that says what the thing is
- a small, real example first, with its parts in **bold**
- headings that state an idea, not "Overview"
- a `<Code>` block the reader can change and break

Press **CC** to see a textbook column, one of the visuals a page can use:

Before you draw, write four lines: what the reader must believe, the objects, the one action and what changes, and the wrong idea it prevents. The `markless-anatomy` skill in `.ruler/skills/` has the full recipe.

## Write like you're talking to a friend

- Plain words, short sentences, and "you".
- Define a word the first time you use it.
- No error codes in sentences; a live example shows them.
- Cards or a short list, not a table, unless it's a lookup grid.

## Spotted a missing picture?

Open an issue, even if you can't draw it. Paste these four lines and fill them in:

```text title="issue"
Page:      /concepts/computed
Believe:   the total follows the price without being told
Objects:   a price tag and a receipt
Change:    drag the price; only the total moves
```

## Preview, then open a pull request

Check your page in light and dark, wide and phone-sized. Then run the checks:

```bash title="terminal"
pnpm --dir website run typecheck
pnpm ci:local --fast
```

Open a pull request. Macroscope, the review bot, leaves its findings; answer each one. When the checks are green, it joins the merge queue. [Your first PR](/contributing/first-pr) walks through it.
