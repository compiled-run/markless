# A tour of the Markless repo

<PageMeta time="2 min" assumes="nothing" />

<Subtitle text="Most packages form one pipeline: one half reads your .tsrx files before your app runs, and the other half runs the result wherever you pick." />

Press the map, and ride `Counter.tsrx` from stop to stop:

<TransitMapFigure />

Each stop is a package in `packages/`. The purple line works before your app runs, and the green line runs the result.

## Compile time

- **`@markless/compiler`** reads `.tsrx` and plans it: semantic graph, state lowering, payload planning, emit. Imports `serializer`.
- **`@markless/bundler`** runs the compiler inside Vite or Rolldown. Build-time prerendering lives here too, as a preview. Imports `compiler`, `serializer` and `web`.
- **`@markless/typescript-plugin`** gives editors `.tsrx` support, and holds the repo's `src/tsc.ts` checker. Imports `compiler`.

The compiler doesn't import `web`, but the code it writes does: compiled components import helpers from `@markless/web/fns/*`.

## Render anywhere

- **`@markless/web`** renders and resumes for the web: `render` in a browser, `renderToString` and `renderToStream` for HTML. Imports `runtime` and `serializer`.
- **`@markless/runtime`** is the state graph: reads, writes, computed values and the flush journal. Imports `serializer`.
- **`@markless/serializer`** holds value serialization and the payload protocol types. Imports nothing.
- **`@markless/core`** is the one import for apps: `state`, `computed`, `shared`, `element` and `storage`, plus `render`, `renderToString` and the Vite plugin. Imports `web`, `bundler` and `router`.

A server render and a browser render are two phases of one runtime in `web`, so there's no `packages/server`. No package imports one that depends on it.

## Around the pipeline

- **`@markless/router`** (`packages/router`): file routes, navigation and streaming, built on Nitro.
- **`create-markless`** (`packages/cli`): creates apps from the four starters.
- **`@markless/vitest-browser`**, **`@markless/analyzer`**: browser tests, and checks of a running app.
- **`@markless/ui`**, **`@markless/icons`**, **`@markless/ui-tools`** (`packages/headless/`): UI components, icon packs and their build tools.

## Everything else

- `specs/` holds the behavior contract, `.ruler/` the agent rules and skills, and `docs/` the CI process.
- `demos/` holds demo apps, `poc/fixtures/proofs/` the proof fixtures, `scripts/` the CI, release and benchmark tools, and `website/` this site.

Start at `specs/framework-design.md`. `CONTRIBUTING.md` lists `goals/`, `dist/` and `.witness/` as local or generated output, so skip them while you read.
