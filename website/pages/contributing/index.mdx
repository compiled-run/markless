# The Markless repo

<PageMeta time="2 min" assumes="nothing" />

<Subtitle text="The Markless repo is one pnpm workspace whose packages form a pipeline: half of them compile your .tsrx files before your app runs, and half run the result." terms="compile" />

```bash title="Terminal"
$ ls packages
analyzer  bundler  cli  compiler  core  headless  router
runtime  serializer  typescript-plugin  vitest-browser  web
```

**`core`** is the one package an app imports. The rest either turn a `.tsrx` file into code before your app runs, or run that code.

## Follow one file through the repo

A *pipeline* is a chain where each package hands its output to the next. Press **Next stop**, or use the arrow keys, to follow `map.tsrx` from the code you write to a live page:

<TourFigure />

- Each stop opens the package's real folder, so you know where to read next.
- Hover a branch to see the packages beside the route: tools for your editor, your tests and new apps.
- No package imports one that depends on it, so the route only runs one way.

## The rest of the repo holds specs, demos and this site

- `specs/` holds the behavior contract, `.ruler/` the agent rules and skills, and `docs/` the CI process.
- `demos/` holds demo apps, `poc/fixtures/proofs/` the proof fixtures, `scripts/` the CI, release and benchmark tools, and `website/` this site.

Start at `specs/framework-design.md`. `CONTRIBUTING.md` lists `goals/`, `dist/` and `.witness/` as local or generated output, so skip them while you read.

[Dev setup](/contributing/dev-setup) gets every package building on your machine.
