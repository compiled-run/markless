# What the compiler writes for the cart

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="The compiler cuts one .tsrx file into small pieces with stable IDs: one function per event and per update, and a record that ties them to elements." />

Press the drawing to make the cut. It all happens at build time, before the page runs anywhere. Every excerpt below is the real output of `compileTsrxModule()` from `@markless/compiler` for the cart:

```tsrx title="cart.tsrx"
import { state } from '@markless/core';

export default function Cart() @{
	let bags = state(0);

	<section>
		<p>In your cart: {bags} bags</p>
		<button onClick={() => bags++}>Add to cart</button>
	</section>
}
```

## The cut is a chain of passes

A *pass* is one small step with named inputs and outputs. The first one runs the analyzer over the file and writes the *semantic graph*: every piece of state, element, read and write, with what each one means. If the chain itself is broken, the compile stops with `MARKLESS_COMPILER_PASS_GRAPH_INVALID`.

## Each frame is a symbol

A *symbol* is one function with a stable ID, in a module of its own. The click became `symbol:0`, an update to the graph node `state:bags`:

```js title="symbol:0"
import { marklessWriteScalar } from "@markless/web/fns/write-scalar";
/* scalar leaf marker: context.graph.update({ */
export function symbol_0(context) {
  return marklessWriteScalar(context, { graphNodeId: "state:bags", returnValue: "next", update(value) {
    return Number(value) + 1;
  } });
}
```


The text became `symbol:1`, which returns one `setText` for `h1`, the paragraph. The view record is the edit list: a click on `h2` runs `symbol:0`, and a change to `state:bags` runs `symbol:1` against `h1`.

## Two render modules

The same compile writes a server module, `marklessRenderSsr`, and a browser module. For a component this simple, the browser one is a *direct module*: it keeps `state:bags` in a plain `Map`, clones the elements from a template and puts the click listener on the button. Props, child components, a scoped `<style>`, a `computed()` or an async block each send a component down the general path instead.
