# What the compiler writes

<PageMeta time="3 min" assumes="state, events" />

<Subtitle text="The compiler turns one .tsrx file into small pieces with stable IDs, before the page runs anywhere." terms="events" />

```tsrx title="chat.tsrx"
import { state } from '@markless/core';

export default function Chat() @{
	let draft = state('Hi');

	<p>Typing: {draft}</p>
}
```

**`draft`** becomes the node `state:draft`. **`{draft}`** becomes `symbol:1`, a small function that sets that one line's text when `draft` changes.

## Every line becomes named pieces

A *symbol* is one small function with a stable ID, in a module of its own:

- each `state()` becomes a node, like `state:draft`
- each handler becomes a symbol, like `symbol:0`
- each spot that shows a value becomes an update symbol, like `symbol:1`

Hover a line, then press **Edit** and change it. The compiler runs in your browser:

<ExplorerAnatomy />

- Each piece points back at the line it came from.
- Change `state('Hi')` to a plain `'Hi'`: the node and its update disappear, and the build names the handler that still writes it.

## The pieces are planned by a chain of passes

A *pass* is one small step with named inputs and outputs. The first one runs the analyzer and writes the *semantic graph*: every value, element, read and write in the file. The 16 passes, in the order they run:

For a component this simple, the browser module is a *direct module*: it keeps `state:draft` in a plain `Map` and puts the listener on the input itself. Props, child components, a scoped `<style>` or a `computed()` send a component down the general path instead.
