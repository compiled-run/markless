# Lazy chunks

<PageMeta time="3 min" assumes="state, events, elements" />

<Subtitle text="Each chunk of click code downloads with the page, and runs only when its own click happens." terms="chunk" />

```tsrx title="gallery.tsrx"
import { state } from '@markless/core';

export default function Gallery() @{
	let open = state('');

	<button onClick={() => (open = 'Bay')}>Bay</button>
}
```

**`onClick`** becomes a small function of its own. It downloads while the page loads, and **runs** only when someone presses **Bay**.

## What a small page pays

Measured in Chromium for a one-page `@markless/router` app with one button and one line of text (uncompressed, main at `2efb1c6e2`):

- **Executed at load:** 8.4 kB, four small inline scripts and the router's link script.
- **Downloaded at load, not executed:** 23.6 kB, fetched with `modulepreload` at low priority.
- **Executed on the first click:** that same 23.6 kB, with nothing new to download.

## Every handler and update is a symbol

The compiler cuts a component into *symbols*: one small function each for an event handler, a text or attribute update, an `attach={...}` behavior, a `computed()` recipe, a `state()` starting value and an `@if` or async update. A symbol runs only when its trigger fires, and no handler runs at mount.

## Packing decides which file holds which code

Production client builds put the symbols into a few files, cut by what each page needs and when:

| Pack | Holds | Downloads |
| --- | --- | --- |
| First use | What the page load and its first interactions run | With the page |
| Navigation | What only a client-side navigation runs | When a navigation is about to happen |
| Deferred | Everything else | On its first `import()` |

Each module in a pack still starts only when something first imports it. Set `packing: false` in the `markless()` options to ship one file per module.

## A symbol reaches only what crosses

A symbol runs after the component body, maybe on another machine, so it can use only state, computed values, element handles, props, `shared()` values, imports and plain constants.

```tsrx title="gift-note.tsrx"
import { element, state } from '@markless/core';

export default function GiftNote() @{
	const field = element<HTMLInputElement>();
	let status = state('idle');

	<section>
		<input el={field} placeholder="Gift note" />
		<button onClick={() => {
			field?.focus();
			status = 'writing';
		}}>
			Focus
		</button>
		<output>{status}</output>
	</section>
}
```
