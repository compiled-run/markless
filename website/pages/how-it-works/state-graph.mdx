# The state graph

<PageMeta time="3 min" assumes="state, computed, events" />

<Subtitle text="The state graph is a list, written at compile time, of which values each spot on the page reads." terms="values" />

```tsrx title="playlist.tsrx"
import { computed, state } from '@markless/core';

export default function Playlist() @{
	let playing = state('Harbour Lights');
	const heading = computed(
		() => 'Now playing: ' + playing,
	);

	<p>{heading}</p>
}
```

**`playing`** is a value the page watches. **`heading`** is worked out from it. **`{heading}`** is the one spot that shows it, so a change to `playing` reaches that line and nothing else.

## The graph is written before the page runs

The compiler turns each `state()` and `computed()` into a *node*, and each spot that reads one into a *subscription*:

- `state:playing` is a node
- `computed:heading` reads `state:playing`
- the `<p>` text reads `computed:heading`

Press **Slow Train**, then **Shuffle**, and watch the graph:

<GraphAnatomy />

- Slow Train lights one path, `playing` to `heading` to the paragraph.
- Pressing it again does nothing: the value is the same, so the graph stops.
- `shuffle` has no readers, so changing it changes nothing on the page.

## A write runs only its own path

When `playing` changes, `@markless/runtime`:

1. marks `state:playing` changed and `computed:heading` stale,
2. waits for the current code to finish, then runs one *flush*,
3. runs only the subscriptions on that path and applies the page changes they return.

```tsrx title="playlist.tsrx"
import { computed, state } from '@markless/core';

export default function Playlist() @{
	let playing = state('Harbour Lights');
	const heading = computed(
		() => 'Now playing: ' + playing,
	);

	<p>{heading}</p>
}
```
</Code>

- Two writes in the same turn share one flush.
- A write to `song.title` doesn't reach a reader of `song.artist`; replacing `song` reaches both.
- `@markless/core` has no effect function. The compiler plans every subscription.
