# One file, every device

<PageMeta time="3 min" assumes="state, events" />

<Subtitle text="You write a component once, and Markless works it out at compile time for every place it runs." terms="events" />

```tsrx title="seatmap.tsrx"
import { state } from '@markless/core';

export default function SeatMap() @{
	let seat = state('A2');

	<p>Your seat: {seat}</p>
}
```

**`seat`** is a value the page watches, and **`{seat}`** is the spot that shows it. That is the whole plan, and it doesn't say which device it runs on.

## The plan is the same on every host

Drag the file onto each host, then pick a seat:

- The browser draws the plan as a web page.
- A server prints the plan as the HTML it sends.
- The phone draws it with native buttons. Native is an early proof: the web is what ships.

## Pick where it renders

The compiled component is the same in each place; only the call changes:

| Environment | How you call it | What it is good for |
| --- | --- | --- |
| Browser | `render(App, { target })` from `@markless/core` | A plain Vite app with no server at all |
| Server | `renderToString()` from `@markless/core`, or `renderToStream()` from `@markless/web/render-to-stream` | HTML that is ready when it arrives |
| Multi-page app | `@markless/router` | File routes on Nitro, which deploys to many hosts |
| Tests | `render()` and `renderSSR()` from `@markless/vitest-browser` | Browser tests, with or without a server render first |
| Build time | `MARKLESS_PRERENDER=1` in the repo's demos | A preview, with no public option yet |
| iOS and macOS | See [native targets](/how-it-works/native-targets) | Hand-written proofs, not wired to the compiler |

## What stays the same everywhere

- **Setup runs once.** On a server the body runs there, and the browser never runs it again.
- **No handler runs before its event.** Fetching code early is not running it.
- **A write reaches only its readers.** Nothing compares an old page with a new one.
