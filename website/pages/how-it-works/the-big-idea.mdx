# One file, every device

<PageMeta time="2 min" assumes="state, events" />

<Subtitle text="You write a component once, and Markless works it out when you compile it, for every place it runs." terms="component compile" />

```tsrx title="seatmap.tsrx"
import { state } from '@markless/core';

export default function SeatMap() @{
	let seat = state('A2');

	<p>Your seat: {seat}</p>
}
```

**`seat`** is a value the page watches, and **`{seat}`** is the spot that shows it. That is the whole plan, and it doesn't say which device it runs on.

## The plan is the same on every host

Drag the file onto each host, then pick a seat:

<SeatAnatomy />

- The browser draws the plan as a web page.
- A server prints the plan as the HTML it sends.
- The phone draws it with native buttons. Native is an early proof: the web is what ships.

## What stays the same everywhere

- **Setup runs once.** On a server the body runs there, and the browser never runs it again.
- **No handler runs before its event.** Fetching code early is not running it.
- **A write reaches only its readers.** Nothing compares an old page with a new one.
