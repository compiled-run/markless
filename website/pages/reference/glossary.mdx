```tsrx title="guest-list.tsrx"
import { state } from '@markless/core';

export default function GuestList() @{
	let guests = state(['Ada', 'Grace']);

	<ul>
		@for (const name of guests; key name) {
			<li>{name}</li>
		}
	</ul>
}
```

Three words from the index below are in this file: **`GuestList`** is a *component*, **`guests`** is *state*, and **`key name`** is the *key* that gives each row its identity.
