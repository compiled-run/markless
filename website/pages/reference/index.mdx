# Markless packages

<PageMeta time="2 min" assumes="nothing" />

<Subtitle text="Markless is a set of npm packages that share one version number: you install a few, and they bring the rest." />

```json title="package.json"
"dependencies": {
	"@markless/core": "{{marklessVersion}}",
	"@markless/router": "{{marklessVersion}}"
},
"devDependencies": {
	"@markless/analyzer": "{{marklessVersion}}",
	"@markless/typescript-plugin": "{{marklessVersion}}"
}
```

A new app from `npm create markless` lists four Markless packages: **`core`** and **`router`** to run the app, and **`analyzer`** and **`typescript-plugin`** to check it. The CLI fills in `{{marklessVersion}}` as a `^` range of its own version:

<ReleaseVersion />

## You install four packages, and they bring the rest

A *dependency* is a package another package needs, which npm installs along with it. Press the terminal to install `@markless/core`, then click a package to delete it:

<PackagesFigure />

- Each package lands after the package that needs it.
- Delete one, and every package that needs it turns red.
