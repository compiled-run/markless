## Packages you install

A new app from `npm create markless` installs four Markless packages. Press the drawing to see what they bring along:

<PackagesFigure />

You install the packages in this table yourself. The ones in the next table come along with them.

| Package | What it gives you |
| --- | --- |
| `@markless/core` | `state`, `computed`, `shared`, `element` and `storage`. Also `render()` for the browser, `renderToString()` for HTML, and the Vite plugin at `@markless/core/vite`. |
| `@markless/router` | Apps with many pages: file routes in `pages/`, `Html`, `Link`, `navigate()`, and the Vite plugin at `@markless/router/vite`. It builds through Nitro, which deploys to many hosts. |
| `@markless/typescript-plugin` | Editor support for `.tsrx` files. See [Editor setup](/tooling/editor-setup). |
| `@markless/vitest-browser` | `render()` and `renderSSR()` for tests in a real browser. See [Testing](/tooling/testing). |
| `@markless/analyzer` | Checks a running app in the browser: console errors, network requests, event wiring and JavaScript budgets you set. The Playwright driver is at `@markless/analyzer/playwright`. |
| `create-markless` | Creates a new app. See [CLI](/reference/cli). |

## Packages the others use

| Package | What it does |
| --- | --- |
| `@markless/compiler` | Reads `.tsrx` files and plans the state, the updates and the code each event runs, before your app runs. |
| `@markless/bundler` | Runs the compiler inside Vite and Rolldown. |
| `@markless/runtime` | Keeps state: reads, writes and computed updates. |
| `@markless/serializer` | The format for the state and page data that travel with rendered HTML. |
| `@markless/web` | The render code behind `render()` in the browser and `renderToString()` for HTML. |

## Not on npm yet

- **`@markless/ui`**: headless, accessible UI components. See [UI components](/ui). It waits on the two packages below. npm still holds an old `0.4.0` from before these pages.
- **`@markless/icons`**: icon packs as `<pack.icon />` tags, inlined at build time.
- **`@markless/ui-tools`**: the build tools behind `@markless/ui`.

[The glossary](/reference/glossary) gives one meaning for each word these packages use.
