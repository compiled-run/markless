# Answer requests with API routes

<PageMeta level="Building" time="5 min" assumes="routes" sprite="arrow-straight" />

<ThemeToggle />

Pages answer with HTML. Sometimes you want JSON, a webhook, or a health check for your host. For
those, you want a plain function that takes a request and returns a response.

Put that function in a file in `api/`, at the root of your app. The `api/` folder is a second street
map next to `pages/`, with the same address rules. One extra rule: the file name can also say which
HTTP method it answers.

Pick a method and an address.

<ApiAnswersDemo />

Try **POST** with `/api/users/42`. The answer is 404, because the file name says `get`.

## One file, one endpoint

Save this as `api/users/[id].get.ts`:

```ts
import type { EndpointHttpContext } from '@markless/router';

export const cache = { maxAge: 60 };

export default function user({ params }: EndpointHttpContext<{ id: string }>) {
	return Response.json({ id: params.id });
}
```

`GET /api/users/42` now answers `{"id":"42"}`, with the header
`cache-control: public, max-age=60, s-maxage=60`. The only cache form the router reads is
`export const cache = { maxAge: <seconds> }`.

| File in `api/` | What it answers |
| --- | --- |
| `health.ts` | every method on `/api/health` |
| `index.ts` | `/api` |
| `users/[id].get.ts` | only `GET` on `/api/users/` plus one part |
| `files/[...path].ts` | `/api/files/` plus one part or more |

The method names a file can end with are `get`, `post`, `put`, `patch`, `delete`, `head`, `options`,
`connect` and `trace`.

Your function gets one object with `request`, `url`, `params`, `locals` and `response`. Set headers
on `response.headers`, or return your own `Response`.

## Run code on every request with middleware

A file in `middleware/` runs for each request to your pages and endpoints. The full-stack starter
ships this one as `middleware/request.ts`:

```ts
export default function request(http: import('@markless/router').MiddlewareHttpContext) {
	http.response.headers.set('x-markless-router', '1');
}
```

That header shows up on your pages and on your `/api/` answers. A middleware file follows the same
rule as an endpoint: one `export default` function.
