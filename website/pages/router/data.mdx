# Page data arrives in the same response

<PageMeta time="2 min" assumes="async, routes" />

<ThemeToggle />

<Subtitle text="A page loads its data with an async computed() inside @try. The fast part of the page shows first, and the data follows in the same response." />

```tsrx title="pages/shops/[shop].tsrx"
import { computed } from '@markless/core';
import type { PageProps } from '@markless/router';
import { recentOrders } from '../../src/orders.ts';

export default function Orders({ params }: PageProps<{ shop: string }>) @{
	const orders = computed(async () => recentOrders(params.shop));

	<main>
		<h1>Recent orders</h1>
		@try {
			<p>{orders.length} orders today</p>
		} @pending {
			<p>Loading orders…</p>
		} @catch {
			<p>Couldn't load the orders.</p>
		}
	</main>
}
```

There is no special loader function. A page loads data the way any component does, as an [async value](/concepts/async).

## One response, in two parts

If `recentOrders` is slow, the server answers in two parts of one response:

1. The heading and the `@pending` text go out first, so the reader sees **Loading orders…** straight away.
2. When the data is ready, the same response adds the `@try` content. The page puts it in place, and the response ends.

The browser never makes a second trip for the data. If it is ready quickly, it goes out in the first part, and **Loading orders…** is never sent. You turn nothing on.

## Read props before or after `await`

The call can use the page's props on either side of an `await`, and Markless tracks both reads:

```tsrx
const orders = computed(async () => {
	const list = await recentOrders(params.shop);
	const status = new URLSearchParams(url.search).get('status');
	return status ? list.filter((order) => order.status === status) : list;
});
```

Keep in mind:

- On the server, `fetch` needs a full address with a host. Build it from the `url` prop: `new URL('/api/orders', url.href)`.
- The router can't wait for all the data before it sends the page. A slow `@try` always sends its `@pending` content first.
