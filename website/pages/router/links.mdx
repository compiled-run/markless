# Links the build can check

<PageMeta time="2 min" assumes="routes" />

<Subtitle text="Link to a route pattern and pass its params. The build checks both, so a link with a typo never ships." />

```tsrx title="pages/index.tsrx"
import { Link } from '@markless/router';

export default function Home() @{
	<nav>
		<Link href="/about">About</Link>
		<Link href="/blog/[slug]" params={{ slug: 'hello' }}>
			First post
		</Link>
	</nav>
}
```

`Link` renders a real `<a>`. The build writes the second one as `href="/blog/hello"`.

## The build checks every pattern

- A pattern that matches no file in `pages/` stops the build.
- A pattern without its `params` stops the build and names them.
- A plain address like `/about` isn't checked by the build; your editor flags its typos.

```txt
Typed route error: /blog/[id] does not match any route in pages/.
```

## A click swaps in only the page

Press the drawing to click the other link. Watch what changes, and when.

<LinkAnatomy />

The router fetches the next page's middle and swaps it in. The address changes at that moment, not at the click. Back and Forward restore each page and its scroll, and Back before the page arrives cancels it.

## The next page is fetched early

A pointer resting on a link, a focus or a press starts the fetch before the click. That fetch is a real `GET`, so turn it off for links that do something, like logging out:

```tsrx
<Link href="/logout" prefetch={false}>Log out</Link>
```

The router never fetches other sites, `/api/` paths, or links with `download`, a `target` or `rel="external"`.

## Navigate from code

```tsrx title="checkout.tsrx"
import { navigate } from '@markless/router';

export default function Checkout() @{
	<button
		onClick={async () => {
			await fetch('/api/orders', { method: 'POST' });
			await navigate('/orders', { replace: true });
		}}
	>
		Place order
	</button>
}
```

`navigate()` does what a click does, and resolves once the new page is in place.

Keep in mind:

- `replace` swaps the current history entry, and `scroll={false}` keeps the scroll position. Both work on `Link` and `navigate()`.
- `prefetch={false}` works on `Link`, a plain `<a>`, or a component that passes it to one. Anywhere else stops the build with `MARKLESS_ELEMENT_ONLY_ATTRIBUTE_MISPLACED`.
- `router({ prefetch: false })` in `vite.config.ts` turns early fetches off everywhere.

Pages often need data from somewhere slow. [Load it in the page](/router/data).
