# Make a file, get a URL

<PageMeta time="2 min" assumes="components" />

<Subtitle text="Each file in pages/ is one page of your app, and its path on disk is its address." />

```tsrx title="pages/about.tsrx"
export default function About() @{
	<h1>About the shop</h1>
}
```

Save that file, and `/about` shows **About the shop**. Every `npm create markless` starter includes `@markless/router`, which does this.

## The file name is the address

Press the drawing to drop the address on the card.

<CatalogueAnatomy />

A bracket in a file name is a blank the address fills in. `blog/[slug].tsrx` answers `/blog/hello` with `slug` set to `hello`.

| File in `pages/` | Address |
| --- | --- |
| `index.tsrx` | `/` |
| `blog/[slug].tsrx` | `/blog/` plus one part |
| `docs/[...slug].mdx` | `/docs/` plus one part or more |
| `404.tsrx` | anything else, with status 404 |

A plain name beats `[param]`, and `[param]` beats `[...rest]`.

## Read the params

```tsrx title="pages/blog/[slug].tsrx"
import type { PageProps } from '@markless/router';

export default function Post({ params }: PageProps<{ slug: string }>) @{
	<h1>Post {params.slug}</h1>
}
```

Every page gets four props: `params`, `url`, `status` and `http`. A catch-all param is one string, like `guide/intro`.

## Answer with a status

```tsrx title="pages/invoices/[id].tsrx"
import type { PageProps } from '@markless/router';
import { findInvoice } from '../../src/invoices.ts';

export default function Invoice({ params, http }: PageProps<{ id: string }>) @{
	const invoice = findInvoice(params.id);
	if (!invoice) http.response.status = 404;

	<h1>{invoice ? invoice.title : 'No such invoice'}</h1>
}
```

Set the status before anything the page waits on. Changing it later throws `MARKLESS_ROUTER_RESPONSE_COMMITTED`.

Keep in mind:

- `document.tsrx` in the app root wraps every page, using `Html` from `@markless/router`. It can't hold event handlers.
- Two files for one address stop the build, like `docs.tsrx` next to `docs.mdx`.
- `http` exists only on the server. Reading it in a handler stops the build with `MARKLESS_SERVER_ONLY_PROP_BROWSER_READ`.
