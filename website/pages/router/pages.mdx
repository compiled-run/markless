# Make a file, get a URL

<PageMeta time="3 min" assumes="components" />

<Subtitle text="Each file in pages/ is one page of your app, and its path on disk is its address." />

```tsrx title="pages/about.tsrx"
export default function About() @{
	<h1>About the shop</h1>
}
```

Save that file, and `/about` shows **About the shop**. The *router* is the part of your app that turns an address into a page. `@markless/router` does it, and every `npm create markless` starter includes it.

## The file name is the address

| File in `pages/` | Address |
| --- | --- |
| `index.tsrx` | `/` |
| `about.tsrx` | `/about`, and `/about/` too |
| `docs/index.mdx` | `/docs` |
| `blog/[slug].tsrx` | `/blog/` plus one part, like `/blog/hello` |
| `docs/[...slug].mdx` | `/docs/` plus one part or more |
| `404.tsrx` | any address with no matching file, with status 404 |
| `500.tsrx` | a page that throws in a production build, with status 500 |

- Page files end in `.tsrx` or `.mdx`. Any other file in `pages/`, like a helper `.ts`, is skipped.
- A plain name beats `[param]`, and `[param]` beats `[...rest]`. So `blog/new.tsrx` answers `/blog/new`, and `blog/[slug].tsrx` answers the rest.
- In the dev server, a page that throws shows the Markless error page instead of `500.tsrx`.

## Read the params

A *param* is the part of the address a bracket stands for. The page gets it as a prop:

```tsrx title="pages/blog/[slug].tsrx"
import type { PageProps } from '@markless/router';

export default function Post({ params }: PageProps<{ slug: string }>) @{
	<h1>Post {params.slug}</h1>
}
```

`/blog/hello` shows **Post hello**. A catch-all param is one string, so for `/docs/guide/intro`, `slug` is `guide/intro`.

Every page gets four props: `params`, `url`, `status` and `http`.

## Answer with a status

An invoice that doesn't exist should still show a message, but answer 404. Then browsers, search engines and caches know the page is missing. The `http` prop is how a page talks to the response:

```tsrx title="pages/invoices/[id].tsrx"
import type { PageProps } from '@markless/router';
import { findInvoice } from '../../src/invoices.ts';

export default function Invoice({ params, http }: PageProps<{ id: string }>) @{
	const invoice = findInvoice(params.id);
	if (!invoice) {
		http.response.status = 404;
		http.response.headers.set('cache-control', 'no-store');
	}
	const title = invoice ? `Invoice ${invoice.number}` : `No invoice ${params.id}`;

	<h1>{title}</h1>
}
```

`GET /invoices/42` now answers 404, with **No invoice 42** as its body. The status and headers leave with the first bytes of the page, so set them before anything the page waits on. Changing them later throws `MARKLESS_ROUTER_RESPONSE_COMMITTED`.

## Wrap every page in one document

There is no layout file. `document.tsrx` in the app root wraps every page, using `Html` from `@markless/router`. Each page arrives as `children`:

```tsrx title="document.tsrx"
import type { Children } from '@markless/core';
import { Html } from '@markless/router';

export default function Document({ children }: { readonly children?: Children }) @{
	<Html>
		<head>
			<meta charset="utf-8" />
			<meta name="viewport" content="width=device-width, initial-scale=1" />
		</head>
		<body>{children}</body>
	</Html>
}
```

For a header and footer that some pages share, write a [component](/build/components) that takes `children`, and wrap each page's content in it.

Not yet:

- Two files for one address stop the build, like `docs.tsrx` next to `docs.mdx`. So do a partial bracket like `post-[id].tsrx`, a catch-all that isn't the last part, and a `404.tsrx` or `500.tsrx` inside a folder.
- `http` exists only on the server. Reading it in a handler, `attach` or `computed()` stops the build with `MARKLESS_SERVER_ONLY_PROP_BROWSER_READ`, so copy the one value the browser needs into `state()`.
- `document.tsrx` can't hold event handlers. An `onClick` there stops the build with `MARKLESS_ROUTER_DOCUMENT_HANDLERS_UNSUPPORTED`.
