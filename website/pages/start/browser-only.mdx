# One HTML page, one empty div, no server

<PageMeta level="Start here" time="5 min" assumes="nothing" sprite="square" />

<ThemeToggle />

Sometimes you want one interactive thing on one page. You do not want a router, or a server to run.

Markless works there too. You need two packages, `@markless/core` and `vite`, and five small files. The build gives you plain static files.

**`render(App, { target })` runs your component once and puts what it made into the element you pass.**

## Build it

Make an empty folder and add these five files.

### 1. package.json

```json
{
	"name": "my-counter",
	"private": true,
	"type": "module",
	"scripts": {
		"dev": "vite",
		"build": "vite build",
		"preview": "vite preview"
	}
}
```

Then install the two packages:

```bash
npm install @markless/core vite
```

### 2. index.html

The page has one empty `div`. Your component goes inside it.

```html
<!doctype html>
<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>My Markless app</title>
	</head>
	<body>
		<div id="app"></div>
		<script type="module" src="/src/main.ts"></script>
	</body>
</html>
```

### 3. vite.config.ts

The `markless()` plugin teaches Vite to read `.tsrx` files.

```ts
import { markless } from '@markless/core/vite';
import { defineConfig } from 'vite';

export default defineConfig({
	plugins: [markless()],
});
```

### 4. src/main.ts

This file finds the empty `div` and renders `App` into it.

```ts
import { render } from '@markless/core';
import App from './App.tsrx';

const target = document.querySelector('#app');
if (!target) throw new Error('Missing #app');

await render(App, { target });
```

### 5. src/App.tsrx

This is the same counter as on the [first page](/).

```tsrx
import { state } from '@markless/core';

export default function App() @{
	let count = state(0);

	<button onClick={() => count++}>Count {count}</button>
}
```

## Run it

```bash
npm run dev
```

Open `http://localhost:5173` and click **Count 0**. The number goes up. `App` ran once, in the browser, and each click changes only the number.

When you are ready to ship, build it:

```bash
npm run build
```

The `dist/` folder now holds `index.html` and a `build/` folder of JavaScript files. Any static file host can serve `dist/`. Run `npm run preview` to try the built version on your machine.
