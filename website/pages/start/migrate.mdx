# Migrating an existing app

<PageMeta level="Start here" time="2 min" assumes="nothing" sprite="arrow-curve" />

<ThemeToggle />

<Subtitle text="markless-migrate moves your app to Markless one page at a time, and proves each page still works the same before it goes live." />

## What it does

Your coding agent rewrites a page. markless-migrate opens the old page and the new one side by side, clicks everything, and compares what people, search engines and screen readers get. A page only goes live when they match. Until then, your old app keeps serving it.

<MigrateAnatomy />

## Try it

It works through the coding agent you already use, like Claude Code, Codex or Cursor. It is a preview and not on npm yet.

```bash
npx @markless/migrate setup
```
