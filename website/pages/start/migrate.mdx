## How it works

<MarkedText text="Your coding agent rewrites one page. markless-migrate then opens the old page and the new one side by side and checks them like a picky tester: what people see, what search engines and screen readers get, and how fast it loads. If anything differs, the page doesn't switch, and your old app keeps serving it. ## Set it up

<AgentLogos lead="Works with" end=":" />

```bash
npx @markless/migrate setup
```

It's a preview, so it's not on npm yet. MIT licensed, [source on GitHub](https://github.com/compiled-run/markless-migrate).

## Will it work for my app?

It has moved Next.js, Remix, Angular, React, Vue, htmx and Alpine.js apps, from source code or from the live site alone.

Not yet:

- Charts, maps, editors and 3D views drawn on a canvas keep their original library.
- Requests your server makes are compared only on Node servers.
- Requests that save or delete data are held back, so point it at test data.
- Pages behind bot protection need a staging URL or bypass token.
