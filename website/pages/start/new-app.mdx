## Create your app

Here is a pretend terminal. Press Enter to see what the command creates, then hover any file to see what it's for. Prefer pnpm, Yarn or Bun? Type that instead, and every command on this page switches to match.

<CreateAnatomy />

Now do it in your real terminal:

<Commands kind="create" />

Every question has a sensible default, so Enter, Enter, Enter is fine. Nothing touches your disk until you pick **Create app**.

## Start the dev server

The dev server is what runs while you work. It serves your app at `localhost:3000` and updates the page every time you save. Try it here first:

<DevServer />

Then, in your app's folder:

<Commands kind="dev" />

Open `localhost:3000`. You'll see a heading and a button that counts.

## Make a change

That whole page is one file, `pages/index.tsrx`. Here it is, live. Click **Count 0** a few times, then work through these:

<Code steps={[{ label: 'Change the heading to `My first app`.', shows: 'My first app' }, { label: 'Start the count at `10` instead of `0`.', source: 'state(10)' }, { label: 'Under the button, add `<p>Clicked {count} times</p>`. Click the button, and both lines update.', rewrites: 2 }]}>
```tsrx title="index.tsrx"
import { state } from '@markless/core';

export default function Home() @{
	let count = state(0);

	<main>
		<h1>Markless Router</h1>
		<button onClick={() => count++}>
			Count {count}
		</button>
	</main>
}
```
</Code>

Now make the same edit in your real file and save. The page updates on its own.

One thing worth knowing: the file name is the URL. `index` is `/`, so `pages/about.tsrx` is `/about`.
