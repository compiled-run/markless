# Creating a new app

## Create it

Open a terminal in the folder that will hold your project, and run:

<Commands kind="create" />

It asks a few questions. Press Enter on each one to take its default. Nothing is written until you pick **Create app**.

Here is what you just got: one page, the few config files that build it, and your editor already set up. The drawing below makes the same app. Press Enter in it to run the command, then hover or tap each file to read what it is for. Use pnpm, Yarn or Bun? Type its command there instead, and every command on this page switches to it.

<CreateAnatomy />

## Run it

Go into your new app's folder and start the dev server:

<Commands kind="dev" />

Open `http://localhost:3000`. You see the starter page: a heading and a button that counts. The dev server updates the page every time you save. Here is the same thing running right here:

<DevServer />

All of that page comes from one file, `pages/index.tsrx`.

## Change it

Here is that file, live. Click **Count 0** a few times, then try these:

<Code steps={[{ label: 'Change the heading to `My first app`.', shows: 'My first app' }, { label: 'Start the count at `10` instead of `0`.', source: 'state(10)' }, { label: 'Under the button, add `<p>Clicked {count} times</p>`. Click the button, and both lines update.', rewrites: 2 }]}>
```tsrx title="index.tsrx"
import { state } from '@markless/core';

export default function Home() @{
	let count = state(0);

	<main>
		<h1>Markless Router</h1>
		<button onClick={() => count++}>
			Count {count}
		</button>
	</main>
}
```
</Code>

Make the same change in your own `pages/index.tsrx` and save it. The page at `localhost:3000` shows it.

The file is named `index`, so it is the page at `/`. Add `pages/about.tsrx`, and you have a page at `/about`.

## Ship it

Build your app, then serve the build to click through exactly what your users will get:

<Commands kind="ship" />

The build is a Node server by default, and it can target Vercel and other hosts. [Deploying](/router/deploying) shows how.
