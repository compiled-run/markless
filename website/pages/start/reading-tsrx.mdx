```tsrx title="guest-list.tsrx"
import { state } from '@markless/core';

export default function GuestList() @{
	let guests = state(['Ada', 'Grace']);

	<h2>{guests.length} going</h2>
}
```

`{ }` holds a **value**: `{guests.length}` becomes `2`. `@{ }` holds **instructions**: they run top to bottom, and the last one is what shows up.

## `{ }` holds a value

A value is an *expression*: anything that produces a result. If it fits after `let x =`, it's an expression. One per pair of braces, and it can go:

- in text: `<p>{name}</p>`
- in an attribute: `class={name === 'Ada' ? 'host' : ''}`
- as a handler: `onClick={clear}`

<PrintoutAnatomy figure="values" />

<Code steps={[{ label: 'Click RSVP. All three values change.', shows: 'See you there' }, { label: "Change `'Coming?'` to `'Are you in?'`.", source: 'Are you in?' }]}>
```tsrx title="rsvp.tsrx"
import { state } from '@markless/core';

export default function Rsvp() @{
	let going = state(false);

	<section>
		<style>
			.yes {
				font-weight: bold;
			}
		</style>
		<h2>{going ? 'See you there' : 'Coming?'}</h2>
		<button
			class={going ? 'yes' : 'maybe'}
			onClick={() => (going = !going)}
		>
			{going ? 'Going' : 'RSVP'}
		</button>
	</section>
}
```
</Code>

## `@{ }` holds instructions, run top to bottom

An instruction is a *statement*: a line that runs, like `let guests = state([])` or `@if (…) { … }`. Most hold a value, such as [`state([])`](/concepts/state) or [`computed(() => …)`](/concepts/computed).

<PrintoutAnatomy figure="steps" />

- Statements first, then one element. No `return`.
- Several elements? Wrap them in `<>` and `</>`.
- Need a few more steps among the elements? Open another `@{ }`.

<Code note="After </section>, add <p>See you!</p> and read the build error. Then wrap both in <> and </>.">
```tsrx title="party.tsrx"
export default function Party() @{
	const guests = ['Ada', 'Grace', 'Linus'];
	const host = guests[0];

	<section>
		<p>Hosted by {host}</p>
		@{
			const others = guests.length - 1;
			<p>Plus {others} guests</p>
		}
	</section>
}
```
</Code>

- Two elements at the end, or a statement after the element, stops the build with `MARKLESS_PARSE_ERROR`.
- A nested `@{ }` doesn't work straight inside a top-level `<>` yet.
- Already use TypeScript? It works here too.

## Blocks that start with @

Parentheses hold a value; braces hold instructions.

| Block | What it does |
| --- | --- |
| `@if` / `@else` | show this or that |
| `@for` / `@empty` | once per item |
| `@switch` / `@case` | pick one |
| `@try` / `@pending` / `@catch` | wait for a slow value ([Async](/concepts/async)) |

<PrintoutAnatomy figure="blocks" />

<Code steps={[{ label: "Add `'Linus'` to the list. `@for` draws one more line.", source: 'Linus' }, { label: 'Click Clear. The `@if` line shows up.', shows: 'No one yet' }]}>
```tsrx title="guest-list.tsrx"
import { state } from '@markless/core';

export default function GuestList() @{
	let guests = state(['Ada', 'Grace']);

	<section>
		<h2>{guests.length} going</h2>
		@for (const name of guests; key name) {
			<p>{name}</p>
		}
		@if (guests.length === 0) {
			<p>No one yet</p>
		}
		<button onClick={() => (guests = [])}>
			Clear
		</button>
	</section>
}
```
</Code>

- An `@if` or `@switch` can't sit inside another `@if` yet.
- A `const` at the top of an `@try` body doesn't work yet.
