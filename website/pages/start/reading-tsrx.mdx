## Values and instructions

A **value** is an *expression*: anything that produces a result. `{total}`, `{bags * 14}`, `{isOpen ? 'Close' : 'Open'}` and `onClick={() => total++}` each hold one. If it could go after `let x =`, it's an expression.

An **instruction** is a *statement*: a line that runs. `let total = state(0);`, `const price = computed(() => bags * 14);`, `@if (…) { … }` and `@for (const bag of bags; key bag.id) { … }` are statements.

Statements usually contain expressions: in `let total = state(0)`, the `state(0)` part is an expression, and in `@if (bags > 3)`, `bags > 3` is.

## `{ }` holds a value

Braces hold one expression. Put them in the text between tags, in an attribute, or hand an element a function to run.

The jar is `bags`. Each wire ends at a hole: the button's number, the number in its title, and its click. Press the button: the click runs into the jar, and the new value runs out into both holes.

## `@{ }` holds instructions, run top to bottom

Statements first, then the one element that shows up. There's no `return`. To show several elements, wrap them in `<>` and `</>`, which adds nothing to the page.

Each line on the card is a statement. Reload: they run from the top, the first three leave a value on the desk, and the last one puts the receipt on the page.

<Code note="After </section>, add <p>Thanks!</p> and read the build error. Then wrap both in <> and </>.">
```tsrx title="receipt.tsrx"
export default function Receipt() @{
	const price = 14;
	const bags = 3;
	const total = price * bags;

	<section>
		<p>{bags} bags at {price} dollars</p>
		@{
			const tip = total / 10;
			<p>Tip: {tip} dollars</p>
		}
		<p>Total: {total} dollars</p>
	</section>
}
```
</Code>

A second element at the end, or a statement after it, stops the build with `MARKLESS_PARSE_ERROR`. A nested `@{ }` works inside an element, but not straight inside a top-level `<>` yet.

## Blocks that start with `@`

A line that starts with `@` among the elements is a block. Its parentheses hold a value. Its braces hold instructions.

The list is an `@for`: one row per bag. The flap is an `@if`: it opens once there are three bags. Press Add a bag and watch both.

<BlocksAnatomy />

- `@if (…) { … } @else { … }` shows one side or the other.
- `@for (const bag of bags; key bag.id) { … } @empty { … }` repeats once per item.
- `@switch (…) { @case …: { … } @default: { … } }` picks one case.
- `@try { … } @pending { … } @catch { … }` waits for a slow value. See [Async](/concepts/async).

<Code steps={[{ label: 'Click Add a decaf until shipping is free.', shows: 'Free shipping!' }, { label: 'Click Empty the cart. The `@empty` row takes over.', shows: 'Your cart is empty.' }]}>
```tsrx title="cart-list.tsrx"
import { computed, state } from '@markless/core';

export default function CartList() @{
	let bags = state([
		{ id: 'house', name: 'House blend' },
		{ id: 'dark', name: 'Dark roast' },
	]);
	const left = computed(() => 3 - bags.length);

	<section>
		<ul>
			@for (const bag of bags; key bag.id) {
				<li>{bag.name}</li>
			} @empty {
				<li>Your cart is empty.</li>
			}
		</ul>
		@if (left <= 0) {
			<p>Free shipping!</p>
		} @else {
			<p>Add {left} more for free shipping.</p>
		}
		<button
			onClick={() =>
				(bags = [
					...bags,
					{
						id: 'decaf' + bags.length,
						name: 'Decaf',
					},
				])
			}
		>
			Add a decaf
		</button>
		<button onClick={() => (bags = [])}>
			Empty the cart
		</button>
	</section>
}
```
</Code>

Today, an `@if` or `@switch` can't sit inside another `@if`, and a `const` at the top of an `@try` body doesn't work yet.

## Calls that set how a value behaves

- `state(2)` makes a value the page keeps up with. [State](/concepts/state)
- `computed(() => bags * 14)` works a value out from others. [Computed](/concepts/computed)
- `element()` gives you a handle to a real element. [Reach a real element](/build/elements)
