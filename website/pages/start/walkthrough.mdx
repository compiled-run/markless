## Change one line, see your page change

Here is that file, live. Click **Count 0** a few times, then try these:

<Code steps={[{ label: 'Change the heading to `My first app`.', shows: 'My first app' }, { label: 'Start the count at `10` instead of `0`.', source: 'state(10)' }, { label: 'Under the button, add `<p>Clicked {count} times</p>`. Click the button, and both lines update.', rewrites: 2 }]}>
```tsrx title="index.tsrx"
import { state } from '@markless/core';

export default function Home() @{
	let count = state(0);

	<main>
		<h1>Markless Router</h1>
		<button onClick={() => count++}>
			Count {count}
		</button>
	</main>
}
```
</Code>

Make the same change in your own `pages/index.tsrx` and save it. The page at `localhost:3000` shows it.

The file is named `index`, so it is the page at `/`. Add `pages/about.tsrx`, and you have a page at `/about`.

## Ship it, one script at a time

Your app comes with these scripts:

<Commands kind="scripts" />

`dev` is where you spend your day. Before you ship, run `build` and then `preview`. It serves the real production build, so you click what your users will get.

Something wrong with the setup? Run the `doctor` script first (Deno apps do not have one). It checks that the `@markless/*` packages are there, on matching versions. It checks the editor wiring in `tsconfig.json`, and then it runs a build.

## Try a different starter

Every starter writes the same base files, then a few of its own. Pick a different answer to the first question in the terminal above to see exactly which files each one writes.

To skip the questions, name the folder, add `--yes` and pick a starter:

<Commands kind="starters" />

`--yes` takes the default for every question a flag did not answer. The other flags: `--format` with `node`, `deno` or `bun`, `--no-install`, `--no-git`, `--agents` with a list or `none`, `--workspace` or `--no-workspace`, and `--force` to write into a folder that is not empty.
