# Read a Markless error in four lines

<PageMeta time="2 min" assumes="lists" />

<Subtitle text="When Markless can't make a piece of code work, it stops the build and tells you what broke, why, how to fix it, and where to read more." />

This list builds. Take its key away, and read what Markless says.

<Code note="On the @for line, delete ; key item and read the error under the result. Reset puts the key back.">
```tsrx title="list.tsrx"
import { state } from '@markless/core';

export default function List() @{
	let items = state(['Milk', 'Eggs']);

	<section>
		<ul>
			@for (const item of items; key item) {
				<li>{item}</li>
			}
		</ul>
		<button
			onClick={() => {
				items = [...items, 'Tea ' + items.length];
			}}
		>
			Add an item
		</button>
	</section>
}
```
</Code>

## Read the error line by line

An **error** stops the build. A **warning** shows as a wavy line in your editor, and the build goes on. Press the ticket to read what `npm run build` prints for the list with no key:

<CitationFigure />

Each error gets four lines, in this order, and the location in line 1 takes you to the code. The fix fits on one line, and line 3 suggested it.

## Silence a warning, with a reason

If you accept a warning on purpose, write `// markless-allow CODE: reason` on the line above it, or on the same line:

<PermitFigure />

Break one of the comment's rules, and Markless raises a warning of its own:

| Code it raises | Rule |
| --- | --- |
| [`ALLOW_REASON_REQUIRED`](/errors/MARKLESS_ALLOW_REASON_REQUIRED) | Write a reason after the colon. |
| [`ALLOW_ERROR_UNSUPPRESSIBLE`](/errors/MARKLESS_ALLOW_ERROR_UNSUPPRESSIBLE) | An error can't be silenced. Fix it. |
| [`ALLOW_STALE`](/errors/MARKLESS_ALLOW_STALE) | When the warning stops firing there, delete the comment. |

## Codes you'll meet first

Every code starts with `MARKLESS_`, so the table leaves that out.

| Code | Kind | What to do |
| --- | --- | --- |
| [`FRAMEWORK_IMPORT_REQUIRED`](/errors/MARKLESS_FRAMEWORK_IMPORT_REQUIRED) | error | Add `import { state } from '@markless/core'`. |
| [`STATE_MODULE_SCOPE`](/errors/MARKLESS_STATE_MODULE_SCOPE) | error | Move `state()` into the component body. |
| [`STATE_CREATION_SITE_UNSTABLE`](/errors/MARKLESS_STATE_CREATION_SITE_UNSTABLE) | error | Create `state()` in the body itself, not in an `@if`, a loop, a handler or a `computed()`. |
| [`STATE_STALE_LOCAL_WRITE`](/errors/MARKLESS_STATE_STALE_LOCAL_WRITE) | error | A handler writes a plain `let` the page shows. Wrap its value in `state()`. |
| [`REPEAT_KEY_REQUIRED`](/errors/MARKLESS_REPEAT_KEY_REQUIRED) | error | Add a key to the `@for`, like `key item.id`. |
| [`REPEAT_KEY_IS_INDEX`](/errors/MARKLESS_REPEAT_KEY_IS_INDEX) | warning | Key by a field that stays with the item. Keep `key i` only if row state belongs to the position. |
| [`ASYNC_BOUNDARY_REQUIRED`](/errors/MARKLESS_ASYNC_BOUNDARY_REQUIRED) | error | Wrap the async read in `@try` with `@pending` and `@catch`. |
| [`STATE_WRITE_IN_COMPUTED`](/errors/MARKLESS_STATE_WRITE_IN_COMPUTED) | error | Move the write into an event handler. |

[All error codes](/errors) lists every one, grouped by the package that raises it.
