# Testing

<PageMeta time="2 min" assumes="state,events" />

<Subtitle text="A browser test puts your component in a real browser, clicks its elements the way a visitor would, and checks what the page shows." terms="elements" />

```ts title="todo.browser.ts"
import { render } from '@markless/vitest-browser';
import { expect, test } from 'vite-plus/test';
import TodoItem from './TodoItem.tsrx';

test('a click marks it done', async () => {
	await render(TodoItem);
	const button = document.querySelector('button')!;
	button.click();
	await expect.poll(() => button.textContent).toBe('Buy milk: done');
});
```

**`render(TodoItem)`** puts the component on a real page. **`button.click()`** presses it, and **`expect.poll`** waits until the text reads `Buy milk: done`.

## A test clicks a real button

A *browser test* runs in Chromium, so a click runs your real handler. Press **Run**, then click the handler to break it and run again:

<RunnerFigure />

- With the handler working, the row goes green.
- With it broken, the text never changes and the test fails at its `expect`.

## The component is plain Markless

This is the `TodoItem` the test clicks. Change it, and watch the result:

<Code steps={[{ label: 'Rename the item to `Buy bread`.', shows: 'Buy bread: to do' }, { label: 'Start it done.', source: 'state(true)' }]}>
```tsrx title="TodoItem.tsrx"
import { state } from '@markless/core';

export default function TodoItem() @{
	let done = state(false);

	<button onClick={() => (done = !done)}>
		Buy milk: {done ? 'done' : 'to do'}
	</button>
}
```
</Code>

Rename it, and the test above fails too: it still expects `Buy milk: done`.

## Set it up once

The starters don't include this yet. In an app from `npm create markless`, add the packages and a browser:

```bash
npm install -D @markless/vitest-browser playwright @vitest/browser-playwright@<vitest version>
npx playwright install chromium
```

`npx vp --version` prints the Vitest version your app already has. Use that same version for `@vitest/browser-playwright`, or npm refuses the install.

```ts title="vitest.config.ts"
import { markless } from '@markless/core/vite';
import { testSSR } from '@markless/vitest-browser/ssr-plugin';
import { playwright } from 'vite-plus/test/browser-playwright';
import { defineProject } from 'vite-plus/test/config';

export default defineProject({
	plugins: [testSSR(), markless()],
	test: {
		include: ['src/**/*.browser.ts'],
		browser: {
			enabled: true,
			headless: true,
			provider: playwright(),
			instances: [{ browser: 'chromium' }],
		},
	},
});
```

Put both files in `src/`, and run `npx vp test run --config vitest.config.ts`.

- Wait with `expect.poll`. A click's change can land a moment after `click()` returns.
- Each test starts on an empty page: the package removes what it mounted after every test.

## Server pages use `renderSSR`

If your app renders its pages on a server, use `renderSSR(TodoItem)` instead of `render`. It renders the component to HTML on the test server and puts that HTML in the page, and your test clicks the same button.

- `testSSR()` must come before `markless()` in the config. Without it, `renderSSR()` throws `was not transformed`.
- Write `renderSSR(TodoItem)` by name, with a component from its own `.tsrx` file and no props. A helper that gets `renderSSR` passed in as a value skips the rewrite and throws.
