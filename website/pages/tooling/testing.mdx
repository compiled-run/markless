# Test a component in a real browser

<PageMeta time="2 min" assumes="state,events" />

<Subtitle text="@markless/vitest-browser puts your component in a real browser, and your test clicks it, the way a visitor would." />

```ts title="counter.browser.ts"
import { render } from '@markless/vitest-browser';
import { expect, test } from 'vite-plus/test';
import Counter from './Counter.tsrx';

test('a click counts', async () => {
	await render(Counter);
	const button = document.querySelector('button')!;
	button.click();
	await expect.poll(() => button.textContent).toBe('Count 1');
});
```

A type check never clicks a button. This test does: it shows `Counter`, clicks it, and waits for the new text.

## Two ways in

A component can start in the browser, or arrive as HTML from a server. A bug can hide in one way and not the other, so the package gives you both:

| Helper | What it does |
| --- | --- |
| `render(Counter)` | Mounts `Counter` in the browser, the way an app with no server does. |
| `renderSSR(Counter)` | Renders `Counter` to HTML on the test server, then puts that HTML in the page. |

Only the first step differs. After it, your test clicks the same button and reads the same text.

## Set it up

The starters don't include this yet. In an app from `npm create markless`, add the packages and a browser:

```bash
npm install -D @markless/vitest-browser playwright @vitest/browser-playwright@<vitest version>
npx playwright install chromium
```

`npx vp --version` prints the Vitest version your app already has. Use that same version for `@vitest/browser-playwright`, or npm refuses the install.

```ts title="vitest.config.ts"
import { markless } from '@markless/core/vite';
import { testSSR } from '@markless/vitest-browser/ssr-plugin';
import { playwright } from 'vite-plus/test/browser-playwright';
import { defineProject } from 'vite-plus/test/config';

export default defineProject({
	plugins: [testSSR(), markless()],
	test: {
		include: ['src/**/*.browser.ts'],
		browser: {
			enabled: true,
			headless: true,
			provider: playwright(),
			instances: [{ browser: 'chromium' }],
		},
	},
});
```

`testSSR()` must come before `markless()`. Without it, `renderSSR()` throws `was not transformed`.

## Write the check once, run it both ways

Put both files in `src/`. `Counter` is the starter's button:

```tsrx title="Counter.tsrx"
import { state } from '@markless/core';

export default function Counter() @{
	let count = state(0);

	<button onClick={() => count++}>Count {count}</button>
}
```

The check is one function. Each test runs its own first step, then calls it:

```ts title="counter.browser.ts"
import { render, renderSSR } from '@markless/vitest-browser';
import { expect, test } from 'vite-plus/test';
import Counter from './Counter.tsrx';

async function clickCounts() {
	const button = document.querySelector('button')!;
	button.click();
	await expect.poll(() => button.textContent).toBe('Count 1');
}

test('mounted in the browser', async () => {
	await render(Counter);
	await clickCounts();
});

test('rendered on a server', async () => {
	await renderSSR(Counter);
	await clickCounts();
});
```

Run it with `npx vp test run --config vitest.config.ts`. Both tests pass, in Chromium.

- Wait with `expect.poll`. A click's change can land a moment after `click()` returns, so a read straight after it may still see the old text.
- Write `renderSSR(Counter)` by name, with a component from its own `.tsrx` file and no props. A helper that gets `renderSSR` passed in as a value skips the rewrite and throws.
- Each test starts on an empty page: the package removes what it mounted after every test.
