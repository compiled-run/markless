# TypeScript checks a copy of each `.tsrx` file

<PageMeta time="2 min" assumes="components" />

<Subtitle text="Markless hands TypeScript a TSX copy of each .tsrx file. TypeScript checks the copy, and every error points back to the line you wrote." />

`Nav` takes `label: string`, and `app.tsrx` passes it `42`. Press the drawing, and follow the file to the checker and back:

<CopyCheckFigure />

The error lands on `label`, line 4, column 7 of your file. TSX is the file type TypeScript already understands: TypeScript with HTML-like tags. The copy exists only for the checker, and your own file stays exactly as you wrote it.

## What gets checked

The copy keeps your real types, so a mistake shows at the exact spot:

- a prop of the wrong type, or one the component doesn't take
- an attribute HTML elements don't have, like `className` (write `class`)
- a misspelt event handler, like `onClik`
- a handler whose code doesn't type-check

## Where the check runs today

Press the drawing to mark the three places you might expect a check:

<WhereItRunsFigure />

- **In your editor**, on every file you open. [Editor setup](/tooling/editor-setup) turns it on.
- **Not in the build.** `npm run build` stops on Markless errors, but a wrong prop still builds. `npm run check` doesn't check `.tsrx` types either.
- **Not from the command line, yet.** The published `@markless/typescript-plugin` is the editor plugin only, with no command to check every file at once.

Working on Markless itself? The repo has that command: [Dev setup](/contributing/dev-setup) shows `pnpm typecheck`.
