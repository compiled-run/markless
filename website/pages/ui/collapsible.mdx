# collapsible

<ThemeToggle />

<Playground scenario="basic" />

A collapsible is one button that shows or hides one panel. Use it for a "Show more" section or one
question with its answer. For a stack of sections, use [accordion](/ui/accordion).

## Anatomy

<AnatomyTable />

`collapsible.trigger` is a native `<button>`, so Tab reaches it, and Enter and Space press it. It
reports `aria-expanded` and points at the panel with `aria-controls`.

## A closed panel stays in the page

Closing the panel hides it. It does not remove it. So anything inside keeps its state, such as text
typed into a field.

A closed panel gets `hidden="until-found"`. The browser's find-in-page still searches it, and a hit
opens the panel. `onChange` runs with `true` when that happens.

If you set `disableUntilFound`, a closed panel gets plain `hidden` instead, and find-in-page skips
it.

<Callout
	sprite="bolt"
	title="Why did a disabled panel open?"
	text="disabled stops the trigger. It does not stop find-in-page. A disabled panel with until-found still opens when the browser finds text in it. Set disableUntilFound too if it must stay shut."

## Styling

The family ships no CSS. It writes these attributes:

| Attribute | On | When |
| --- | --- | --- |
| `ui-open` | `root`, `trigger`, `content` | The panel is showing. |
| `ui-closed` | `root`, `trigger`, `content` | The panel is hidden. |
| `ui-disabled` | `root` | `disabled` is set. |

<Callout
	sprite="speech-bubble"
	title="Why is my closed panel still showing?"
	text="The panel hides with the hidden attribute. If you give it a display rule, your rule beats the browser's rule for hidden. Write .panel:not([hidden]) { display: grid } instead."
/>

## Props on `collapsible.root`

| Prop | Type | What it does |
| --- | --- | --- |
| `open` | `boolean` | Whether the panel starts open. The default is `false`. |
| `disabled` | `boolean` | The trigger is disabled, so a press does nothing. |
| `disableUntilFound` | `boolean` | A closed panel gets plain `hidden`, so find-in-page skips it. |
| `onChange` | `(open: boolean) => void` | Called with the new value when the panel opens or closes. |

Every other prop goes on the root `<div>`. Your own `onClick` on the trigger runs after the panel
has changed.
