# navbar

<ThemeToggle />

<Playground scenario="basic" />

`navbar` is your site's main navigation. Each entry is a link, or a button that shows a dropdown of
links. Use it for the bar across the top of a site.

It is not a menu bar. It writes no `menu`, `menubar` or `menuitem` role, and the tests check that.
A screen reader hears plain links and buttons, which is what site navigation is.

## Anatomy

<AnatomyTable />

- `navbar.root` is the `<nav>` landmark. It holds which dropdown is showing.
- `navbar.item` is one top-level entry. Its `value` names it.
- `navbar.itemtrigger` is a `<button>` that shows or hides the item's dropdown. It writes
  `aria-expanded` and `aria-controls`.
- `navbar.itemcontent` is the dropdown. It carries `hidden` while it is closed.
- `navbar.itemlink` is an `<a>`. It works at the top level and inside a dropdown.

The root, the item, the trigger and the dropdown write `ui-open` while a dropdown shows. They write
`ui-closed` while it does not. `navbar.item` writes `ui-active` when you set `active` on it.
`navbar.itemlink` writes `ui-active` and `aria-current="page"` when you set `current` on it.

Set `current` on the one link for the page a person is on. Set `active` on the item for the section
that page sits in. Only `current` reaches a screen reader.

## Keyboard

| Key                       | What it does                                                                      |
| ------------------------- | --------------------------------------------------------------------------------- |
| Enter or Space            | Opens or closes the dropdown of the focused trigger.                              |
| Left arrow or Right arrow | Moves between top-level controls, and wraps at the ends. It skips dropdown links. |
| Home or End               | Jumps to the first or last top-level control.                                     |
| Down arrow on a trigger   | Opens the dropdown and moves focus to its first link.                             |
| Arrows inside a dropdown  | Move between that dropdown's links, and wrap at the ends.                         |
| Home or End in a dropdown | Jumps to the dropdown's first or last link.                                       |
| Escape                    | Closes the dropdown. If focus was inside it, focus goes back to the trigger.      |
| Tab                       | Moves on as normal. When focus leaves the landmark, the open dropdown closes.     |

A press outside the open dropdown closes it too.

## Hover

By default a dropdown opens when the pointer rests on its item. The first one waits for `delay`.
Once one shows, the next item opens as soon as the pointer reaches it.

When the pointer leaves the landmark, the dropdown closes after a short grace period. If the pointer
comes back in time, the dropdown stays.

## Name the landmark

`navbar.root` writes no `aria-label`. A page can have a main nav and a footer nav. The same made-up
name on both gives a screen reader two landmarks it cannot tell apart. Write your own label, as in
the example above.

`navbar.itemcontent` gets no placement CSS from the family. Position the dropdown with your own
stylesheet.

## Props on `navbar.root`

| Prop         | Type              | What it does                                                                                    |
| ------------ | ----------------- | ----------------------------------------------------------------------------------------------- |
| `value`      | `string`          | The `value` of the item whose dropdown shows. Omit it, or pass `''`, and every dropdown closes. |
| `hover`      | `boolean`         | Opens a dropdown when the pointer rests on its item. Omit it and hover is on.                   |
| `delay`      | `number`          | How long the pointer rests before the first dropdown opens, in ms. Omit it and it is 200.       |
| `clickGrace` | `number`          | How long a click on the trigger is ignored after a hover opened it, in ms. The default is 300.  |
| `onChange`   | `(value) => void` | Gets the `value` now showing, or `''` when everything closed.                                   |

The root passes anything a `<nav>` accepts to its element. `navbar.item` takes `value`, which is
required, and `active`. `navbar.itemlink` takes `current`.
