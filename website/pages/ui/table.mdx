# table

<ThemeToggle />

`table` is a plain HTML table that can do more. It adds arrow keys from cell to cell, rows a person
can pick, and headers that ask for a sort.

<TableDemo shows="Three preserves. Arrow across the cells, then press Space to pick a row." />

```tsrx
import { table } from '@markless/ui';

const grid = 'border-collapse: collapse; inline-size: min(32rem, 100%); font-size: var(--step--1)';
const title = 'padding-block-end: 0.4em; font-weight: 700; text-align: left';
const head = 'padding: 0.35em 0.6em; border-block-end: 2px solid var(--code-edge); font-size: var(--step--2); letter-spacing: 0.06em; text-transform: uppercase; text-align: left';
const sorts = 'padding: 0.35em 0.6em; border-block-end: 2px solid var(--code-edge); font-size: var(--step--2); letter-spacing: 0.06em; text-transform: uppercase; text-align: left; cursor: pointer';
const cell = 'padding: 0.4em 0.6em; border-block-end: 1px solid var(--code-edge); text-align: left';

export default function Pantry() @{
	<table.root multiple value={['jam']} sort={{ column: 'jars', direction: 'descending' }} style={grid}>
		<caption style={title}>What the pantry put up</caption>
		<thead>
			<tr>
				<th style={head}>Preserve</th>
				<table.coltrigger value="jars" style={sorts}>Jars</table.coltrigger>
				<table.coltrigger value="sealed" style={sorts}>Sealed</table.coltrigger>
			</tr>
		</thead>
		<tbody>
			<table.item value="jam">
				<table.itemcontent rowheader style={cell}>Damson jam</table.itemcontent>
				<table.itemcontent style={cell}>48</table.itemcontent>
				<table.itemcontent style={cell}>In August</table.itemcontent>
			</table.item>
			<table.item value="chutney">
				<table.itemcontent rowheader style={cell}>Green tomato chutney</table.itemcontent>
				<table.itemcontent style={cell}>31</table.itemcontent>
				<table.itemcontent style={cell}>Last week</table.itemcontent>
			</table.item>
			<table.item value="marmalade">
				<table.itemcontent rowheader style={cell}>Seville marmalade</table.itemcontent>
				<table.itemcontent style={cell}>12</table.itemcontent>
				<table.itemcontent style={cell}>In March</table.itemcontent>
			</table.item>
		</tbody>
	</table.root>
}
```

Click a cell, then use the arrow keys. Press Space to pick the row you are on. Hold Shift and press
Down to pick a run of rows.

## You add the extras one at a time

A bare `table.root` around your own `<thead>` and `<tbody>` is a plain HTML table. It writes no
role and no Tab stop. Each part you add turns on one extra:

- Wrap cells in `table.itemcontent`, and the arrow keys move from cell to cell.
- Swap a `<th>` for a `table.coltrigger`, and that column can ask for a sort.
- Write `value`, `onChange` or `multiple` on the root, and rows can be picked. The table then
  becomes `role="grid"`.

The family does no data work. It does not sort, filter or page your rows. It tells you which
header was pressed and which rows are picked. Your own code puts the rows in order.

## When to use it

Use `table` for data in rows and columns, where each column means something. For a list of cards
or rich items, use [gridlist](/ui/gridlist) instead.

## Parts

<AnatomyTable />

- `table.root` is the `<table>`. It holds which rows are picked and which column is sorted.
- `table.item` is one body row, a `<tr>`. Its `value` names the row, and it is required.
- `table.itemcontent` is one cell, a `<td>`. Add `rowheader` and it renders a `<th>` that names its
  row.
- `table.coltrigger` is a column header that asks for a sort, a `<th>`. Its `value` names the
  column.
- `table.itemfield` is a hidden checkbox that sends a picked row to a form. Put it inside a cell,
  because a `<tr>` can only hold cells.

`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, the header row and a plain `<th>` need no parts.
Write them as normal HTML.

## Sort a column

Pressing a `table.coltrigger` calls `onSortChange` with that column's `value`. It does not pick a
direction. Your code decides the next direction, sorts the rows, and passes the result back as
`sort`:

```tsrx
<table.root sort={{ column: 'jars', direction: 'descending' }} onSortChange={turn}>
```

`sort.direction` is `ascending` or `descending`, the same words `aria-sort` uses. Every
`table.coltrigger` writes `aria-sort`. A column that is not the sorted one says `none`.

## Pick rows

Write `value`, `onChange` or `multiple`, and rows can be picked. `value` is the list of picked row
values. `onChange` receives the whole new list each time it changes. With `multiple`, a person can
pick more than one row.

```tsrx
<table.root multiple value={picked} onChange={keep}>
```

## Styling hooks

| Attribute | On | Present when |
| --- | --- | --- |
| `ui-selectable` | root | Rows can be picked. |
| `ui-multiple` | root | `multiple` is set. |
| `ui-disabled` | root, item | The table or this row is disabled. |
| `ui-value` | item, coltrigger | Always. Its value is the row's or column's `value`. |
| `ui-selected` | item | This row is picked. |
| `ui-sorted` | coltrigger | The rows are sorted by this column. |

A table whose rows can be picked gets `user-select: none` from a rule in `@layer markless`. Without
it, a Shift click paints the page's own text selection across the rows. One rule of yours outside a
layer beats it.

## Keyboard

The family's tests check each of these rows. They work once the table has `table.itemcontent` cells
or rows that can be picked. Without cells, the arrows move whole rows.

| Key | What it does |
| --- | --- |
| Left arrow or Right arrow | Moves to the cell before or after. It stops at the ends of the row. |
| Down arrow or Up arrow | Moves to the same column in the next or the previous row. |
| Home or End | Moves to the first or the last cell of the row. |
| Ctrl or Cmd with Home or End | Moves to the first cell of the table, or the last. |
| Space | Picks the row, or lets go of it. |
| Shift and Down arrow or Up arrow | Picks the run of rows from where you started. Needs `multiple`. |
| Ctrl or Cmd and A | Picks every row. Needs `multiple`. |
| Escape | Lets go of every picked row. |
| Letters | Moves to the next row whose text starts with what you typed. |
| Enter or Space on a `table.coltrigger` | Calls `onSortChange` for that column. |

The table is one Tab stop. When focus comes back, it lands on the cell it left. Each
`table.coltrigger` is a Tab stop of its own, outside the arrow walk. The walk skips a disabled row.
