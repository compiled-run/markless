# toggle

<ThemeToggle />

`toggle` is an on/off switch. It is either on or off, never half-way. The family's name is
`toggle` because `switch` is a reserved word in JavaScript.

<ToggleDemo shows="Click the switch or its label. Then Tab to it and press Space." />

```tsrx
import { toggle } from '@markless/ui';

export default function Notifications() @{
	<toggle.root class="row" name="notifications">
		<toggle.label class="label">Email me when an order ships</toggle.label>
		<toggle.trigger class="track">
			<toggle.thumb class="thumb" />
		</toggle.trigger>
		<toggle.field />
	</toggle.root>
}
```

Clicking the words flips the switch too, because the label's `for` points at the trigger. A
screen reader hears a switch named "Email me when an order ships", and whether it is on.

## When to use it

Use `toggle` for a setting that takes effect at once, such as notifications. If the choice only
counts when a form is sent, or it can be mixed, use [checkbox](/ui/checkbox) instead.

## Parts

<AnatomyTable />

- `toggle.root` holds whether the switch is on, and what a form receives. It renders a `<div>`.
- `toggle.trigger` is the switch. It is a `<button>` with `role="switch"` and `aria-checked`.
- `toggle.thumb` is a `<span>` for the moving dot. It does nothing on its own. Your CSS moves it.
- `toggle.label` names the switch. Clicking it flips the switch.
- `toggle.description` is a help line. The switch points at it with `aria-describedby`.
- `toggle.error` is an error message. The switch points at it too, before the help line.
- `toggle.field` is a hidden checkbox that sends the switch to a form. Tab never reaches it.

`name`, `value` and `required` go on the root, and `toggle.field` reads them from there. A form
receives `value` under `name` while the switch is on. If you leave `value` out, the form gets
`on`. A switch that is off or disabled sends nothing.

## Styling hooks

| Attribute | On | Present when |
| --- | --- | --- |
| `ui-checked` | root, trigger | The switch is on. |
| `ui-disabled` | root, trigger | `disabled` is set on the root. |

The thumb writes no attributes. Style it from its parent, such as
`.track[ui-checked] .thumb { translate: 1.4em 0 }`.

## Keyboard

`toggle.trigger` is a native button, so it takes focus with Tab.

| Key | What it does |
| --- | --- |
| Space or Enter | Flips the switch. |

A disabled switch ignores clicks, Space and Enter. It never calls `onChange`.
